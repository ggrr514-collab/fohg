# クラスまど

学級ごとの時間割・持ち物・課題・連絡・学校行事をまとめて見られる、
Google Apps Script（GAS）+ スプレッドシートの学級ダッシュボードです。

- `Code.gs` … サーバー側ロジック（スプレッドシートに紐づけて使う）
- `Index.html` … クライアント側（Webアプリ画面）

## セットアップ（共通）

1. テンプレートのスプレッドシート（`クラス設定`「利用者情報」「担当割当」「時間割」「設定」「予定」「課題」「提出状況」「連絡」の各シートを持つもの）を用意する
2. 「拡張機能 > Apps Script」で `Code.gs` と `Index.html` を貼り付ける
3. 「デプロイ > 新しいデプロイ > ウェブアプリ」で公開する
   - 実行ユーザー: 自分／アクセスできるユーザー: ドメイン内全員

## 学校行事の取り込み（年間行事予定ファイル連携）

西原中ダッシュボードの `syncEventImportFromR8` と同じ仕組みで、
年間行事予定ファイル（「４月」〜「３月」の月別シートを持つスプレッドシート）から
行事予定を自動抽出できます。

### 対応している月別シートの形式

- シート名が「４月」「10月」のような月名（全角数字・半角数字どちらも可）
- シート内に `日｜曜｜週｜行事計画等｜…｜日課` という見出し行がある
- 見出しより上の行に西暦年（例: 2026）が入っている
  （1〜3月のシートは翌年の西暦になっている想定。見つからない場合は今日の年度から推定）

抽出されるのは **日付・曜日・週（A/B）・行事・日課** で、
このスプレッドシートに自動作成される「行事取込」シートに書き込まれます。
（手動で書き換えても次回の取込で上書きされます）

### 設定手順

1. 年間行事予定のExcelファイルをGoogleドライブにアップロードし、
   **Googleスプレッドシート形式に変換**して保存する
2. そのスプレッドシートのIDを `Code.gs` 冒頭の `EVENT_SS_ID` に設定する
3. 取り込む（どちらでも可）
   - 画面から: 教員が「週間予定」タブ →「今後の学校行事」の **🔄 行事を取り込む** ボタン
   - エディタから: `syncEventsFromMaster` を実行
4. （任意）毎日自動で取り込む場合は、エディタから `setupEventSyncTrigger` を一度実行する
   （毎朝5時台に自動同期するトリガーが作られます）

### 取り込むと変わること

- 「今日の予定」「週間予定」の学校行事欄に、行事予定ファイルの行事が
  **今日以降の分だけ**日付順で表示されます（表示は「4/8（水）」形式）
- 行事予定ファイルの週欄（A/B）から **「今週の週区分」が自動判定**されます。
  自動判定できる間は、教員の手動設定（A週/B週）は不要になります
- 従来どおり「予定」シートへの手入力（クラス別の予定を含む）も併用できます

### 従来方式（行事マスターの「予定」シート）との互換

`EVENT_SS_ID` に「予定」シート1枚形式の行事マスターを指定する従来の使い方も
そのまま動きます（列名の揺れ「タイトル／行事名／行事／内容」「日付／月日」を吸収）。
月別シート形式のファイルを指定した場合は「予定」シートがないため、
取込済みの「行事取込」シートが行事の情報源になります。
