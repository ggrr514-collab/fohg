# クラスまど

学級ごとの時間割・持ち物・課題・連絡・学校行事をまとめて見られる、
Google Apps Script（GAS）+ スプレッドシートの学級ダッシュボードです。

- `Code.gs` … サーバー側ロジック（スプレッドシートに紐づけて使う）
- `Index.html` … クライアント側（Webアプリ画面）

## セットアップ（共通）

1. テンプレートのスプレッドシート（`クラス設定`「利用者情報」「担当割当」「時間割」「設定」「予定」「課題」「提出状況」「連絡」の各シートを持つもの）を用意する
2. 「拡張機能 > Apps Script」で `Code.gs` と `Index.html` を貼り付ける
3. 「デプロイ > 新しいデプロイ > ウェブアプリ」で公開する
   - 実行ユーザー: 自分／アクセスできるユーザー: ドメイン内全員

## 時間割と毎日の連絡の考え方

時間割は「固定のマスター」、毎日の連絡は「日付ごとのデータ」として分けて管理します。

- **時間割（固定）** … 「週間予定」タブでコマをタップして設定（教員のみ）。
  前期・後期の入れ替えなどがない限り、はじめに一度設定すればそのままです。
  コマごとに「毎回の持ち物」（例: 体育の体操服）も設定でき、毎回 🎒 付きで表示されます。
- **今日・明日の教科連絡（毎日更新）** … 「今日の予定」タブに今日と明日
  （金曜・土曜は次の登校日）の時間割が並び、各時限の ✏️ からその日だけの
  教科連絡・持ち物を入力できます（📣 付きで表示）。
  入力できるのは教員（全時限）と、その教科の教科係の生徒です。
  データは「日別連絡」シート（自動作成）に日付つきで保存されるので、
  翌週の同じ曜日に残ってしまうことはありません。

明日の分の週区分（A/B週）は、行事予定ファイルを取り込んでいれば日付ごとに
自動判定されます（週をまたぐ場合も正しく切り替わります）。

### 日付を変えて表示（先の予定・過去の連絡）

「今日の予定」の上部にある日付ナビ（◀ 前の日／日付選択／次の日 ▶）で、
好きな日付に移動できます。先の日付を選んで前もって教科連絡や時間割変更を
入力したり、過去の日付に戻って当時の連絡を見返したりできます。
移動中は「先の予定を表示中」「過去の連絡を表示中」と表示され、
「今日に戻る」ボタンでいつでも今日に戻れます。

### 時間割変更（自動反映と手動変更）

その日の実際の時間割は、次の優先順位で決まります。

1. **教員の手動変更** … 「今日の予定」の各時限の 🔁 ボタン（教員のみ）から
   「この日だけの教科」を入力できます。「時間割変更」シート（自動作成）に
   日付つきで保存され、固定の時間割シートは変更されません。
   赤い「変更」バッジ付きで表示され、空欄で保存すると元に戻ります。
2. **行事予定ファイルの校時** … 年間行事予定の各月シートには学年ごとに
   1〜6時限の校時欄があり（「A水3」=A週水曜3限の授業、「授」=通常どおり、
   「学活」「訓練」などの特別活動名、空欄=その時限なし）、行事取込に含めて
   今日・明日の時間割へ自動反映します。「B月3」のような日は月曜の時間割の
   教科がそのまま表示され、元の校時が（B月3）のように小さく添えられます。
   校時に授業が入っている土曜（公開授業など）は登校日として扱われます。
   ※この機能は「行事を取り込む」を一度実行し直すと有効になります。
3. **固定の時間割** … 上記がない日は通常どおり曜日・週の時間割を表示します。

### 前期・後期の入れ替え

「時間割」シートに見出しに「後期」を含む列（例: 後期教科）を追加して
後期の教科を入力しておくと、**後期開始日（既定: 2026-11-09）以降は自動で
後期の教科が表示**されます。空欄のコマは前期と同じ教科のまま表示されます。
今日・明日の表示は日付ごとに判定するので、切替日の直前の「次の登校日」も
正しく後期で表示されます。
開始日を変えるには「設定」シートに キー「後期開始日」・値「2026-11-09」の
行を追加して書き換えるか、Code.gs の SECOND_TERM_START_DEFAULT を変更します。
※後期開始後に担当の教科が変わる教科係は、「係・担当」で登録し直してください。

## 学校行事の取り込み（年間行事予定ファイル連携）

西原中ダッシュボードの `syncEventImportFromR8` と同じ仕組みで、
年間行事予定ファイル（「４月」〜「３月」の月別シートを持つスプレッドシート）から
行事予定を自動抽出できます。

### 対応している月別シートの形式

- シート名が「４月」「10月」のような月名（全角数字・半角数字どちらも可）
- シート内に `日｜曜｜週｜行事計画等｜…｜日課` という見出し行がある
- 見出しより上の行に西暦年（例: 2026）が入っている
  （1〜3月のシートは翌年の西暦になっている想定。見つからない場合は今日の年度から推定）

抽出されるのは **日付・曜日・週（A/B）・行事・日課** で、
このスプレッドシートに自動作成される「行事取込」シートに書き込まれます。
（手動で書き換えても次回の取込で上書きされます）

### 設定手順

1. 年間行事予定のExcelファイルをGoogleドライブにアップロードし、
   **Googleスプレッドシート形式に変換**して保存する
2. そのスプレッドシートのIDを `Code.gs` 冒頭の `EVENT_SS_ID` に設定する
3. 取り込む（どちらでも可）
   - 画面から: 教員が「週間予定」タブ →「今後の学校行事」の **🔄 行事を取り込む** ボタン
   - エディタから: `syncEventsFromMaster` を実行
4. （任意）毎日自動で取り込む場合は、エディタから `setupEventSyncTrigger` を一度実行する
   （毎朝5時台に自動同期するトリガーが作られます）

### 取り込むと変わること

- 「今日の予定」「週間予定」の学校行事欄に、行事予定ファイルの行事が
  **今日以降の分だけ**日付順で表示されます（表示は「4/8（水）」形式）
- 行事予定ファイルの週欄（A/B）から **「今週の週区分」が自動判定**されます。
  自動判定できる間は、教員の手動設定（A週/B週）は不要になります
- 従来どおり「予定」シートへの手入力（クラス別の予定を含む）も併用できます

### 従来方式（行事マスターの「予定」シート）との互換

`EVENT_SS_ID` に「予定」シート1枚形式の行事マスターを指定する従来の使い方も
そのまま動きます（列名の揺れ「タイトル／行事名／行事／内容」「日付／月日」を吸収）。
月別シート形式のファイルを指定した場合は「予定」シートがないため、
取込済みの「行事取込」シートが行事の情報源になります。
