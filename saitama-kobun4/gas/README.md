# 古典クエスト 配布キット

埼玉県公立高校入試 **大問4（古文）** 対策の学習アプリです。漢字クエスト・語句クエストと同じ
「GASウェブアプリ ＋ 集計スプレッドシート」構成で、**解答履歴が自動でスプレッドシートに保存**されます。

- 全10ステージ・全40問。1ステージ＝本文1つ＋小問4問（各3点／12点満点）で、本番の大問4と同じ構成
- **すべてア〜エの4択記号問題**
- 本文は縦書き表示（横書きに切り替え可）、注つき。採点後に現代語訳と設問ごとの解説
- 設問タイプ別（仮名遣い／主語・語意／内容理解／要旨・話し合い）の弱点分析、まちがえた問題の復習
- ランキング・称号・解答履歴・疑義報告

## 同梱ファイル

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | サーバー側コード（Apps Script に貼り付ける） |
| `index.html` | クライアント側の画面（Apps Script に貼り付ける） |
| `古典クエスト_問題マスター.xlsx` | 問題プール（本文10・設問40。READMEシート付き） |
| `README.md` | このファイル |

> リポジトリの `saitama-kobun4/index.html` は、ログイン不要・記録はブラウザ内のみの**単体版**です。
> スプレッドシートに記録を残す場合は、こちらの `gas/` を使ってください。

## セットアップ手順

### 1. スプレッドシートを2つ用意して、それぞれの ID を取得する

1. **集計用スプレッドシート**（名簿・解答履歴・集計などを保存する方）
   - 新しいスプレッドシートを1つ作成する（名前は「古典クエスト_集計」など）。
   - **語句クエストなどの既存の集計スプレッドシートを、そのまま使うこともできます。**
     このアプリが作るシートは `古典_` で始まる名前なので、既存のシートとぶつかりません。
     その場合、**名簿シートは既存のものがそのまま使われます**（生徒の再入力が不要）。
2. **問題マスター**
   - 同梱の `古典クエスト_問題マスター.xlsx` をドライブにアップロードし、
     右クリック →「アプリで開く」→「Google スプレッドシート」で**スプレッドシート形式に変換**する。

それぞれの**ファイルID**を URL からコピーしておきます。

```
https://docs.google.com/spreadsheets/d/【この部分がID】/edit
```

### 2. 集計用スプレッドシートに Apps Script を貼り付ける

1. **集計用スプレッドシート**を開き、メニュー「拡張機能」→「Apps Script」。
2. 既定の `コード.gs` の中身をすべて消し、同梱の **`Code.gs`** を貼り付ける。
3. 左の「ファイル」横の「＋」→「HTML」を選び、ファイル名を **`index`**（拡張子なし）にして作成。
   - 中身をすべて消し、同梱の **`index.html`** を貼り付ける。
   - ※ファイル名は必ず `index` にすること（コードが `index` という名前で読み込みます）。

### 3. Code.gs の冒頭にある2つの ID を設定する

```javascript
const SPREADSHEET_ID = "ここに集計用スプレッドシートのIDを貼る";
const MASTER_ID      = "ここに問題マスターのIDを貼る";
```

書き換えたら保存します。

### 4. 初回セットアップを実行して、必要なシートを生成する

1. **集計用スプレッドシート**を一度リロードする。
2. メニューに **「⚙ 古典クエスト管理」** が増えるので、
   「⚙ 古典クエスト管理」→ **「初回セットアップ（必要なシートを生成）」** を実行する。
   - 初回は Google の認可画面が出るので、自分のアカウントで許可する。
3. `古典_結果` `古典_解答履歴` `古典_集計` `古典_疑義報告` `古典_設定`（と、無ければ `名簿`）が生成されます。

### 5. 名簿を自校用に書き換える（教員999は残す）

初回セットアップで `名簿` を新規作成した場合、次の3件が入っています。

| 出席番号 | コード | 氏名 |
| --- | --- | --- |
| 999 | 9999 | せんせい |
| 101 | SAMPLE1 | サンプル太郎 |
| 102 | SAMPLE2 | サンプル花子 |

- **999 の行（教員アカウント）はそのまま残す**（消すと教員モードに入れません）。コードは変更可。
- サンプルを消し、自校の生徒を **出席番号・個人コード・氏名** の3列で入力する。
- 既存の集計簿に相乗りした場合は、すでにある名簿がそのまま使われます。

### 6. ウェブアプリとしてデプロイする

1. Apps Script エディタ右上の **「デプロイ」→「新しいデプロイ」**。
2. 種類で **「ウェブアプリ」** を選ぶ。
3. 設定：
   - **次のユーザーとして実行**：**自分（自分のアカウント）**
   - **アクセスできるユーザー**：**全員**
4. 「デプロイ」を押し、表示された**ウェブアプリのURL**をコピーして生徒に配布します。

### 7. 動作確認

- Apps Script エディタで関数 `testConnection` を実行すると、集計簿と問題マスターに
  つながっているか、何ステージ・何問読み込めたかがログに出ます。
- ウェブアプリのURLを開き、出席番号 **999** ／ コード **9999** でログインして出題を確認します。

## 保存されるデータ

| シート | 内容 |
| --- | --- |
| `古典_結果` | 1回の挑戦につき1行。得点・正答率・所要時間・獲得スコア・誤答問題ID など |
| `古典_解答履歴` | **1問につき1行**。問題ID・設問タイプ・生徒の解答・正解・正誤。弱点分析の元データ |
| `古典_集計` | 生徒ごとの合計スコア・挑戦回数・クリア数・称号・順位（保存のたびに更新） |
| `古典_疑義報告` | 生徒からの「この問題がおかしい」報告 |
| `古典_設定` | 授業中ボーナス／時間制限解除のトグル |

得点はクライアントの申告ではなく、**サーバー側で問題マスターと照合して計算**します。
同じ挑戦の二重送信は「重複排除キー」で弾かれます。

## 運用メモ

### 挑戦できる時間
- いつでも挑戦できますが、**深夜 0:00〜5:00 だけは禁止**（睡眠時間の保護）です。
- 教員アカウント（999）は深夜でも挑戦できます。
- `古典_設定` シートのトグルで一時的に解放できます。

### 設定シートのトグル
- **授業中ボーナス（B1）**：ON の間、獲得スコア **×3**。深夜ブロックも解除されます。
- **時間制限解除（B2）**：ON の間、深夜ブロックだけを解除（倍率は付きません）。
- どちらも**授業が終わったら OFF に戻す**こと。

### スコアの計算
```
基礎点   = 正答数 × 100
タイム点 = 5分より速く解いた場合、余った秒数 × 0.5
満点ボーナス = 12点満点なら +200
獲得スコア = (基礎点 + タイム点 + 満点ボーナス) × 倍率
```
20秒未満で提出された回は「まともに読んでいない」とみなし、タイム点を0にして
`不正疑い` 列に印を付けます（得点そのものは正しく記録されます）。

### 問題の追加・修正
- **問題マスター**の「本文」「設問」シートに行を足します（列の説明は問題マスターの README シート参照）。
- 問題IDは全体で重複させないこと。選択肢は4つすべて埋めること（空欄があると出題されません）。
- 追加後は「⚙ 古典クエスト管理」→「問題プールのキャッシュをクリア」を実行すると、
  次回出題から反映されます（キャッシュは最大6時間）。

### 疑義報告
- 生徒は結果画面の「この問題がおかしいと思ったら報告する」から報告できます。
- 「⚙ 古典クエスト管理」→「疑義報告サマリを表示」で件数を確認し、
  `古典_疑義報告` シートのステータス列を「承認」などに更新して運用してください。

## アプリを更新するとき（URLを変えずに差し替える）

1. エディタで内容を更新・保存する。
2. `Code.gs` と `index.html` の `CLIENT_VERSION`（現在は **1**）は**必ず両方同じ値**にする。
   画面側を変えたら数字を1つ上げる（古い画面を開いたままの生徒に再読み込みを促せます）。
3. 「デプロイ」→「デプロイを管理」→ 既存デプロイの編集（鉛筆）→ バージョンを「新バージョン」にして「デプロイ」。
   これで**URLは変わりません**。

## 個人情報についての注意

- **生徒の実名や個人コードが入った「集計用スプレッドシート」は、外部に共有・公開しないでください。**
- 他の先生に渡すときは、`Code.gs` / `index.html` / 問題マスター だけにし、**名簿は同梱しない**こと。
