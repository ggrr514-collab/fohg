# 古典クエスト 配布キット

埼玉県公立高校入試 **大問4（古文）** 対策の学習アプリです。GASウェブアプリ＋集計スプレッドシート構成で、
**解答履歴が自動でスプレッドシートに保存**されます。

- 全10ステージ・全40問。1ステージ＝本文1つ＋小問4問、**1問3点・合計12点満点**
- **すべてア〜エの4択記号問題**
- 本文は縦書き表示（横書きに切り替え可）、注つき
- **入試と同じく、難しい箇所だけ本文中に口語訳**を添えてある（ボタンで消せる）
- 採点後に全文の現代語訳と、設問ごとの解説
- 設問タイプ別（仮名遣い／主語・語意／内容理解／要旨・話し合い）の弱点分析、まちがえた問題の復習
- ランキング・称号・解答履歴・疑義報告

## ログインのしくみ

**Google アカウントのメールアドレスで自動ログイン**します。

1. 生徒がURLを開く → ログイン中の Google アカウント（`18s…@saitama-city.ed.jp`）を取得
2. 「名簿」シートの `email` 列と照合 → 見つかればそのまま自動ログイン
3. 名簿に無い場合だけ、**初回に「18s から始まる番号」と「氏名」を入力** → 名簿へ追記
   → **以後は自動ログイン**

初回登録の画面では、番号はログイン中のアカウントから自動で埋まり、**書き換えられません**。
他人の番号での登録はサーバー側でも弾かれます。

`t15434@…` のように `t＋数字` のアカウントは**教員**として扱われ、深夜の時間制限をバイパスします。

## 同梱ファイル

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | サーバー側コード（Apps Script に貼り付ける） |
| `index.html` | クライアント側の画面（Apps Script に貼り付ける） |
| `古典クエスト_問題マスター.xlsx` | 問題プール（本文10・設問40。READMEシート付き） |

> スプレッドシートに記録を残す場合は、こちらの `gas/` を使ってください。

## セットアップ手順

### 1. スプレッドシートを2つ用意する

**すでに用意済みのものを使う場合は、この手順は飛ばして手順2へ**（IDは Code.gs に入力済みです）。

1. **集計用スプレッドシート**（名簿・解答履歴などを保存する方）
   - 新しいスプレッドシートを1つ作成する（名前は「古典クエスト_集計」など）。
   - **文章読解クエストなど、既存の集計スプレッドシートをそのまま使うこともできます。**
     このアプリが作るシートは `古典_` で始まる名前なので、既存のシートとぶつかりません。
     その場合、**「名簿」シートは既存のものがそのまま使われます**（生徒の再入力が不要）。
2. **問題マスター**
   - 同梱の `古典クエスト_問題マスター.xlsx` をドライブにアップロードし、
     右クリック →「アプリで開く」→「Google スプレッドシート」で**スプレッドシート形式に変換**する。

それぞれの**ファイルID**を URL からコピーしておきます。

```
https://docs.google.com/spreadsheets/d/【この部分がID】/edit
```

### 2. 集計用スプレッドシートに Apps Script を貼り付ける

1. **集計用スプレッドシート**を開き、メニュー「拡張機能」→「Apps Script」。
2. 既定の `コード.gs` の中身をすべて消し、同梱の **`Code.gs`** を貼り付ける。
3. 左の「ファイル」横の「＋」→「HTML」を選び、ファイル名を **`index`**（拡張子なし）にして作成。
   - 中身をすべて消し、同梱の **`index.html`** を貼り付ける。
   - ※ファイル名は必ず `index` にすること。

### 3. Code.gs の冒頭を確認する

2つのIDは**すでに入力済み**です。作り直したときだけ書き換えてください。

```javascript
const SPREADSHEET_ID = "1Yuf_jzWZYfQKaYuZV6LN6-RDAODoOLeX-uyn9nYecwU";
const MASTER_ID      = "1OaMsGfk_-s-BMa_osO3d8hwK04ikP0G34J7TWbs2lJo";

const MAIL_DOMAIN    = "saitama-city.ed.jp";   // 学校のメールドメイン
const STUDENT_PREFIX = "18s";                  // 生徒アカウントの接頭辞
const TEACHER_LOCAL  = /^t\d+$/i;              // 教員アカウントの形
```

学年が上がって接頭辞が変わったら `STUDENT_PREFIX` を書き換えてください。

### 4. 初回セットアップを実行して、必要なシートを生成する

1. **集計用スプレッドシート**を一度リロードする。
2. メニュー「⚙ 古典クエスト管理」→ **「初回セットアップ（必要なシートを生成）」** を実行。
   - 初回は Google の認可画面が出るので許可する。
3. `古典_結果` `古典_解答履歴` `古典_集計` `古典_疑義報告` `古典_設定`（と、無ければ `名簿`）が生成されます。

### 5. 名簿を用意する

「名簿」シートの列は **`email` / `氏名` / `組` / `番号`** です。

| email | 氏名 | 組 | 番号 |
| --- | --- | --- | --- |
| 18s10659@saitama-city.ed.jp | 犬養　歩夢 | ３年１組 | 1 |
| t15434@saitama-city.ed.jp | 田中　康太郎 | | |

- 事前に入れておけば、生徒は**何も入力せずに**自動ログインできます。
- 空のままでも構いません。生徒が初回に番号と氏名を入れると、この表に追記されます。
- 既存の集計簿に相乗りした場合は、すでにある名簿がそのまま使われます。

### 6. ウェブアプリとしてデプロイする

1. Apps Script エディタ右上の **「デプロイ」→「新しいデプロイ」**。
2. 種類で **「ウェブアプリ」** を選ぶ。
3. 設定：
   - **次のユーザーとして実行**：**自分（自分のアカウント）**
   - **アクセスできるユーザー**：**`saitama-city.ed.jp` 内の全員**

> ⚠ **ここが最重要です。**「アクセスできるユーザー」を「全員」にすると、Apps Script は
> ログイン中のメールアドレスを返さなくなり、自動ログインが動きません。
> **必ず学校ドメイン内に限定**してデプロイしてください。

4. 「デプロイ」を押し、表示された**ウェブアプリのURL**を生徒に配布します。

### 7. 動作確認

Apps Script エディタで関数 `testConnection` を実行すると、ログを確認できます。

```
ログイン中のアカウント: t15434@saitama-city.ed.jp
集計簿: 古典クエスト_集計
名簿: 99名
問題マスター: 古典クエスト_問題マスター / 10ステージ・40問
```

「ログイン中のアカウント」が空の場合は、手順6のデプロイ設定を見直してください。

## 保存されるデータ

| シート | 内容 |
| --- | --- |
| `古典_結果` | 1回の挑戦につき1行。得点・満点・正答率・所要時間・誤答問題ID など |
| `古典_解答履歴` | **1問につき1行**。問題ID・設問タイプ・生徒の解答・正解・正誤。弱点分析の元データ |
| `古典_集計` | 生徒ごとの累計得点・挑戦回数・クリア数・称号・順位（保存のたびに更新） |
| `古典_疑義報告` | 生徒からの「この問題がおかしい」報告 |
| `古典_設定` | 授業中モード／時間制限解除のトグル |

いずれも `email` をキーにして記録され、`氏名` `組` `番号` が併記されます。

## 得点の考え方

- **1問3点・1ステージ12点満点**。それだけです。ボーナス点や倍率はありません。
- **累計得点＝ステージごとの自己ベストの合計**（全10ステージなら最大120点）。
  同じステージを何度解いても水増しされず、解き直して点が上がったときだけ増えます。
- 称号は累計得点が満点の何％かで決まります（10%／30%／50%／70%／90%）。
- 得点はクライアントの申告ではなく、**サーバー側で問題マスターと照合して計算**します。
  同じ挑戦の二重送信は「重複排除キー」で弾かれます。
- 20秒未満で提出された回は「まともに読んでいない」とみなし、`不正疑い` 列に印を付けます
  （得点そのものは正しく記録されます）。フォーカス離脱回数も記録されます。

## 運用メモ

### 挑戦できる時間
- いつでも挑戦できますが、**深夜 0:00〜5:00 だけは禁止**（睡眠時間の保護）です。
- 教員アカウント（`t＋数字`）は深夜でも挑戦できます。
- `古典_設定` シートの **授業中モード** または **時間制限解除** を `TRUE` にすると解除されます。
  授業が終わったら `FALSE` に戻してください。

### 本文に口語訳を添える

入試と同じように、難しい箇所だけ本文中に小さく口語訳を出せます。問題マスターの「本文HTML」に
次のように書きます。

```html
<span class="gl">人の書かする仏もおはしけり<i>（人が注文して描かせている仏の絵もあった）</i></span>
```

- 古文のすぐあとに、ひとまわり小さな字で訳が出ます（縦書き・横書きどちらでも）。
- 生徒は画面の「口語訳あり／なし」ボタンで消せます。既定は入試と同じ「あり」です。
- **設問で問われている箇所には付けないでください**（答えが出てしまいます）。
  同梱の10ステージも、傍線部には訳を付けていません。

### 問題の追加・修正
- **問題マスター**の「本文」「設問」シートに行を足します（列の説明は問題マスターの README シート参照）。
- 問題IDは全体で重複させないこと。選択肢は4つすべて埋めること（空欄があると出題されません）。
- 配点の合計が12点になるようにしてください（既定は1問3点×4問）。
- 追加後は「⚙ 古典クエスト管理」→「問題プールのキャッシュをクリア」を実行すると反映されます
  （キャッシュは最大6時間）。

### 疑義報告
- 生徒は結果画面の「この問題がおかしいと思ったら報告する」から報告できます。
- 「⚙ 古典クエスト管理」→「疑義報告サマリを表示」で件数を確認し、
  `古典_疑義報告` シートのステータス列を更新して運用してください。

## アプリを更新するとき（URLを変えずに差し替える）

1. エディタで内容を更新・保存する。
2. `Code.gs` と `index.html` の `CLIENT_VERSION`（現在は **2**）は**必ず両方同じ値**にする。
   画面側を変えたら数字を1つ上げる（古い画面を開いたままの生徒に再読み込みを促せます）。
3. 「デプロイ」→「デプロイを管理」→ 既存デプロイの編集（鉛筆）→ バージョンを「新バージョン」にして「デプロイ」。
   これで**URLは変わりません**。

## 個人情報についての注意

- **生徒の実名とメールアドレスが入った「集計用スプレッドシート」は、外部に共有・公開しないでください。**
- 他の先生に渡すときは、`Code.gs` / `index.html` / 問題マスター だけにし、**名簿は同梱しない**こと。
