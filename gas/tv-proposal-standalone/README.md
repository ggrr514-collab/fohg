# 職員室テレビ表示案（研究部会 提案資料）を学校のURLで見せる方法

このフォルダは、GAS（Google Apps Script）だけで動く**単独の**Webページです。
西原中ダッシュボード本体（別のGASプロジェクト）には一切手を加えません。
提案が通らなかった場合や、会議のあとに不要になった場合は、このプロジェクトごと削除すれば元通りです。

デプロイすると `https://script.google.com/a/macros/saitama-city.ed.jp/s/…/exec` の形の、
学校のアカウントで見られるURLになります。claude.ai のリンクを使わずに、この提案書と
同じ画面イメージ（自動スクロールも実際に動きます）を見せられます。

## 手順

1. [script.google.com](https://script.google.com/) を、学校のGoogleアカウントで開く。
2. 「新しいプロジェクト」を作成する（既存の西原中ダッシュボードのプロジェクトとは**別**のものを新規作成します）。
3. 左側のプロジェクト名を「職員室テレビ表示案」などに変更する（任意）。
4. デフォルトで入っている `Code.gs` の中身を、このフォルダの `Code.gs` の内容にすべて置き換える。
5. 左側の「＋」→「HTML」でファイルを追加し、ファイル名を `Proposal`（拡張子は自動で付きます）にする。
   中身を、このフォルダの `Proposal.html` の内容にすべて置き換える。
6. 上部の「保存」（フロッピーのアイコン、または Ctrl+S）を押す。
7. 右上の「デプロイ」→「新しいデプロイ」を押す。
8. 「種類の選択」の歯車アイコンから「ウェブアプリ」を選ぶ。
9. 次の設定にする。
   - 説明：任意（例：「テレビ表示案 提案資料」）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**「saitama-city.ed.jp」内の全員**（既存のダッシュボードと同じ範囲にしてください。学校のドメイン名が違う場合はそちらに合わせてください）
10. 「デプロイ」を押すと、承認画面が出ることがあります。「アクセスを承認」→自分のアカウントを選択→
    「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」→「許可」。
11. 表示されたURL（ウェブアプリのURL）を、研究部会の案内やチャットで共有する。

## 会議のあとで

- そのまま残しておいても、ダッシュボード本体には影響しません。
- 不要になったら、Apps Script の管理画面からこのプロジェクトを削除するか、
  「デプロイを管理」から該当のデプロイを「アーカイブ」してください。
- 提案の内容を直したいときは、このリポジトリの `gas/tv-proposal-standalone/Proposal.html` を直してもらえれば、
  同じ手順で作り直せます（②〜⑤を Proposal.html の差し替えだけで済ませられます）。
