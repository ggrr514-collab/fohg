# Gemini でお手本を作る手順（可愛げのある線画）

対象: 基礎 17〜49（線・図形の 01〜16 は抽象なので SVG のまま）、発展 01〜30。
できた画像は `samples/basic/NNN.png` / `samples/dev-anime/NNN.png` に **シート番号の名前**で置くだけ。ビルドすると SVG より優先される。

## 1. 生成の設定

- モデル: Gemini の画像生成（Nano Banana 系）。アスペクト比 1:1、できれば 1024×1024 以上
- 1 枚ずつ生成する。まとめ生成はしない（線の太さが揃わない）
- 気に入らなければ「同じ構図で、線をもっと均一に」「顔をもう少し下に」のように**部分指示で再生成**。ゼロからやり直さない
- 発展パックは **`samples/dev-anime/mascot.jpg` を添付して**「このキャラで」と指示する（キャラの一貫性のため）

## 2. 共通スタイル指示（毎回、プロンプトの先頭に貼る）

```
【共通スタイル】
・白い背景に黒い線だけの線画。塗り・影・グレー・色は一切なし
・線は太さ均一の丸みのあるペン線（太めのサインペン）。線はすべて閉じている
・ゆるくて可愛いデフォルメ。丸みを強く、角を作らない。目は黒い丸か大きな丸い目、口は小さく
・要素は少なく。模写の練習用なので、線の数は最小限。細かい模様・ハッチング・質感は描かない
・被写体は1つだけ中央に大きく。周囲に約10%の余白
・文字、記号、ロゴ、透かし、枠線、背景の小物は描かない
・手や指、目の左右など、形が破綻していないこと
Style tags: kawaii, simple line art, thick uniform black outline, no shading, no color, white background, sticker style, minimal details, centered, 1:1
```

## 3. マスコット設定（発展パック用）

**採用済み。** 最初に生成したバストアップ（`samples/dev-anime/001.jpg`、同じものを `mascot.jpg` として保存）をマスコットにする。
以後の発展パックの生成では、**この画像を添付して「このキャラで」**と指示する。文章の設定は次のとおり（画像と食い違う時は画像を優先）。

```
【マスコット】
ゆるかわなアニメ調の女の子。
・ツインテール。頭の上の左右に四角いリボン留め。髪は長く、肩より下まで
・前髪は目にかかる長さで、真ん中で分かれて左右に流れる。両側に長いもみあげ
・顔は丸く、あごは小さい。目は大きくて丸く、黒目に小さなハイライト1つ。まゆ毛は細い曲線
・鼻は小さな点、口は小さな笑い
・服は丸い襟のブラウスに大きなリボン（模様なし）
・5頭身
```

顔だけ・目だけの課題では、「この画像のキャラクターの目」「このキャラの顔だけ」のように画像を指して指示する。
目の描き込み（ハイライトの数、まつげの太さ）は、この画像の目に合わせる。

## 4. 生成後のチェック（模写のお手本として使えるか）

- [ ] 影・グレー・色が入っていない（入っていたら「線だけにして」で再生成）
- [ ] 線が閉じていて、途中で切れていない
- [ ] 手の指は5本、目は左右そろっている、パーツが欠けていない
- [ ] そのシートの「今日のポイント」が見える絵になっている（例: 縦横比の課題なら比率がはっきり違う）
- [ ] 文字・透かし・枠がない
- [ ] 余白がある（切れていない）

## 5. 置き方と反映

```bash
# 画像を samples/<pack>/NNN.png に置く（3桁）
node build/build.mjs basic --all-png
node build/build.mjs dev-anime --all-png
node build/contact-sheet.mjs basic      # 一覧で確認
```

同じ画像を使うシート（発展 01・15・30、基礎 10・30・50）は、同じファイルをコピーして番号を変える。

## 6. 表記

お手本が AI 生成である旨は、BOOTH の説明文・専用ページの FAQ に書いてある。手描きに差し替えた分があれば、その旨に書き換える。
