# Agent A（設計者）の出力

## 1. 指導要領マッチング

### 教材分析

| | 素顔同盟 | 私 |
|---|---|---|
| 設定 | 仮面着用が法制化された社会 | 住民データが「私」を証明する社会 |
| 「私」を消すもの | 仮面（みんなと同じ笑顔） | データ（置き換え可能な情報） |
| 語り手の位置 | 制度を**疑う**側 | 制度を**運用する**側（「模範とされる市民対応」で5年連続表彰） |
| 語り手の自覚 | ある（息苦しさ・後悔・決意） | **ない**（最後まで気づかない） |
| 結末 | 川を上流へ歩きだす＝行動・希望 | 「どちらが消えようが、同じ『私』なのだ。何の問題もない」＝皮肉 |
| 読者の立ち位置 | 語り手に**寄り添って**読める | 語り手より**多く見えてしまう**（劇的アイロニー） |

この落差が単元の装置である。**「素顔同盟」は語り手に共感させ、「私」は語り手を疑わせる。**その体験そのものが「批判的に読む」ことの学習になる。

### 批判的読みの手がかり（発問・ルーブリックの根拠）

**素顔同盟**
- 先生の論「仮面は私たちに真の平和と自由を与えてくれた」は本文上、完全には否定されていない。擁護の根拠も反論の根拠も本文にある。
- 「素顔同盟」という**名称の皮肉**。仮面を捨てた者がまた「同盟」を組む＝新たな同質集団ではないか。
- 川に浮かぶ仮面は、彼女が自ら捨てた証か、排除された証か。**本文は決めていない。**
- 自然／人工、「橋のない川」、「聖域」という二項対立は、作者が作った枠である。

**私**
- 「解決」「誠意」「対応」「模範的」「正常な状態」がカギカッコ付き。語り手自身が中身の空洞に薄々気づきながら使っている。
- 女性を「無理難題タイプ」「論理矛盾タイプ」と**類型で処理する**ことを、有能さとして語る。
- 中盤で自ら「データがなくなったら『私』も消えるのでは」と想像しながら、自分が二重化されると受容する。
- 図書館の司書の対応は、冒頭の語り手の対応の**鏡**である。

### 指導要領との対応（★知技1つ＋思判表1つに限定）

| 区分 | 項目 | この単元での中身 |
|---|---|---|
| **知識及び技能** | **(1)イ**　語感を磨き語彙を豊かにすること | カギカッコに入れられた語（「解決」「誠意」「模範的」「正常な状態」「同盟」）が、価値の空洞や皮肉を運ぶ働きを捉える |
| **思考力・判断力・表現力等** | **C 読むこと (1)イ**　文章を批判的に読みながら、文章に表れているものの見方や考え方について考えること | 二作の語り手の見方を根拠を示して吟味し、結末が肯定するもの・問い残すものを評価する |

- 言語活動：C(2)イ（詩歌や小説などを読み、批評したり、考えたことなどを伝え合ったりする活動）
- 関連指導：B 書くこと (1)イ（資料を適切に引用するなどして説得力のある文章にする）
- 校内フレームとの接続：「読みの観点」第1層**視点・語り**／第3層**批評・評価**が中心。深さは**3（自分の考えをもつ）**を目標段階とする。

### ★ 単元目標（1文）

> **カギカッコに入れられた語などの働きに注意して語感を捉えながら、二つの作品を批判的に読み、それぞれの文章に表れているものの見方や考え方について考えて、「私が私であること」についての自分の考えを批評文にまとめることができる。**

## 2. 発問設計（AI防御型）

### 発問①【知技・語感／教材「私」】　150〜200字

> 『私』の語り手は、「解決」「誠意」「対応」「模範的」「正常な状態」のように、大事な言葉をわざわざカギカッコに入れて使う。この中から**一つ選び**、**あなた自身が「言葉だけは立派なのに中身がない」と感じた経験**を一つ挙げたうえで、語り手がその言葉をカギカッコに入れて使うのはなぜか、自分の言葉で説明しよう。

**AIコピペ不可の理由**：①選択＋理由　②生徒個人の生活体験が必須。AIは生徒の経験を知らない。
**この発問が育てる力**：知技(1)イ（語感）。同時に「語り手が何に薄々気づいているか」という批判的読みの入口になる。

### 発問②【思判表・仮定判断／教材「素顔同盟」】　200〜250字

> 『素顔同盟』の先生は「仮面は私たちに真の平和と自由を与えてくれた」と言う。**もし明日からあなたのクラス全員が仮面をつけることになったら**、何が良くなり、何が失われるだろうか。そのうえで、**先生の主張と「僕」の見方の、どちらがより危ないと思うか**、本文の言葉を引いて書こう。

**AIコピペ不可の理由**：①仮定→判断　②自分のクラスという固有の状況　③「どちらがより危ないか」は選択＋理由。
**この発問が育てる力**：思判表 C(1)イ。**共感しやすい「僕」の側も疑わせる**ことが要点。「先生が間違っている」で終わらせない。

### 指導上の注意（教師向け）
- 発問②で「僕が正しい」一辺倒の回答が出たら、「仮面のおかげで避けられている争いは本文に書かれていないか」と返す。
- 発問①で語を指摘するだけの回答には、「その言葉が普通のカギカッコなしで使われていたら、印象はどう違うか」と問い返す。

## 5. まとめ活動（批評文）

### 場面設定

> **まだ『素顔同盟』も『私』も読んでいない、隣のクラスの友達に向けて**書く批評文。

未読の相手なので、**引用しなければ伝わらない**。B(1)イ（引用して説得力をもたせる）がここで働く。

### 課題

> 二つの作品は、「私が私であること」を**何が支え、何が奪う**と考えているか。二つの作品のものの見方・考え方を検討したうえで、あなた自身の考えを書きなさい。（**800字**）

### 必須条件

| | 条件 |
|---|---|
| **①** | 両作品からそれぞれ**一か所以上引用**し、その作品が「私が私であること」について何を支え・何が奪うと考えているかを示す |
| **②** | 少なくとも一方の作品の見方に対して、「**しかし／とはいえ**」で始まる**疑いの一文**を入れる |
| **③** | （Sの要件）代表者協議で**自分の考えが動いた発言**に触れ、自分の生活や今の社会と結ぶ |

### ★ B/Aの分水嶺

> **条件①と条件②の両方に触れていなければ、A以上にはならない。**
> 引用だけで疑いがない、あるいは疑いだけで引用がない答案は**B止まり**とする。

### 執筆の段取り（A案）

第7時内に**「主張の一段落」200字を書き切る**（主張1文＋両作品からの引用1か所ずつ）。残りは家庭学習で800字に展開して次の授業日に提出。

```
パネル②までのメモを見て、主張を1文で書く   4分
根拠となる引用を両作品から1か所ずつ選ぶ     4分
その3点をつなげて200字で書く              6分
```

## 7. 解答例（全段階・生徒の文体）

同一テーマ「『私が私であること』を支えるのは何か」で、段階差を示す。

### 【S】抜粋

> 二つの作品は、「私」を消すものとして別々のものを出してくる。『素顔同盟』は仮面、『私』はデータだ。『素顔同盟』の先生は「仮面は私たちに真の平和と自由を与えてくれた」と言い、『私』の語り手は最後に「どちらが消えようが、同じ『私』なのだ。何の問題もない」と言う。私はこの二つを読んで、「私」を支えるのは、自分を他人と取りかえられないものとして見てくれる誰かだと考えた。
> 　**しかし**、『素顔同盟』の「僕」の見方を、私は最初そのまま信じていた。仮面を外した彼女を「初めて同類に会えた」と喜ぶ僕に、私も一緒に喜んでいた。**とはいえ**、彼らが向かう先の名前は「素顔同盟」である。仮面を捨てた人がまた「同盟」を組むなら、そこでも「みんなと同じ」が始まるのではないか。僕の見方も、一つの見方にすぎなかった。
> 　班の議論で、ある人が「『私』の語り手のほうが怖い、なぜなら気づいていないから」と言った。私はそれまで、気づいている僕のほうが不幸だと思っていた。**その発言で考えが動いた。**気づかないまま置きかえられるほうが、たしかに怖い。……（以下、自分の生活と結ぶ段落へ）

→ 条件①②③すべて。さらに「僕の見方も一つの見方にすぎなかった」と**自分の読みの前提**に触れている。**S**。

### 【A】抜粋

> 『素顔同盟』では、仮面が「私」を消している。先生は「仮面は私たちに真の平和と自由を与えてくれた」と言うが、僕は「僕は僕でありたい」と思っている。一方『私』では、データが「私」を消している。語り手は最後に「どちらが消えようが、同じ『私』なのだ。何の問題もない」と言ってしまう。
> 　**しかし**、先生の言うことは全部まちがっているとは言えない。本文にも、仮面のおかげでけんかをしないですんでいると書かれている。だから、仮面をなくせばよいという単純な話ではない。私は、「私」を支えるのは、自分の気持ちを表に出せる場所だと考える。

→ 両作品から引用（条件①）、先生の見方に「しかし」で疑いを入れている（条件②）。**両方あるのでA。**協議での変化には触れていないためSではない。

### 【B】抜粋

> 『素顔同盟』では仮面が、『私』ではデータが「私」を消している。『素顔同盟』の僕は「僕は僕でありたい」と思っており、『私』の語り手は「どちらが消えようが、同じ『私』なのだ」と言う。二つの作品はどちらも、社会の仕組みが人を同じにしてしまうことを書いている。私は、「私」を支えるのは自分らしさだと思う。

→ 両作品から引用はある（条件①）が、**どちらの見方も疑っていない**（条件②なし）。**B止まり。**

### 【C】抜粋

> 『素顔同盟』は、仮面をつけないといけない社会で、僕が女の子に出会って、川を上流に歩いていく話だ。『私』は、市役所の人が女の人の対応をして、そのあと自分も二重になってしまう話だ。二つとも少しこわい話だった。私は自分らしく生きたいと思った。

→ あらすじと感想のみ。引用も疑いもない。**C。**

### 【D】抜粋

> 『素顔同盟』を読んで、仮面をつけないといけないのはいやだと思った。自分らしく生きることが大切だと思う。

→ 一方の作品にしか触れていない。**D。**

## 9. 授業者向け・運用上の注意

1. **端末は協議中は伏せる。**提案メモは第4時に紙へ転記しておく。画面を開いたまま協議すると顔が上がらない。
2. **発問①は知識・技能の評価材**なので、AI採点にかけない（教師が見取る）。AIが採点するのは批評文（F列）だけ。
3. **配付・提出はGoogleスプレッドシート形式で行う。**xlsxのまま提出されても収集と採点はできる（Apps Scriptの「サービス」で**Drive API（v2）**を有効化しておくこと）が、**評価の返却（ステップ3）はできない**。収集時に「xlsx形式が何人分あるか」と警告が出るので、該当者には再提出させる。
4. **返却は教師評価が優先。**I列（教師最終評価）に値を入れてから③を実行すると、AI評価ではなくI列の値が生徒に返る。AI評価と食い違う場合は、生徒に返るコメントの冒頭に「評価は先生が確定しています」と自動で注記が入る。採点エラーの文言は生徒に返らない。
5. **組と出席番号は必ず入力させる。**返却先はこの2つで特定している。どちらかが空の提出物は収集時にスキップされ、ファイル名とともに警告が出る。
6. 40人を超える学級では `CONFIG.DATA_END` と教員シートのデータ行を増やす。

### 運用の順序（ここを間違えると手戻りになる）

```
① 集める  →  ② 採点する  →  ③ 返す  →  生徒が自己評価・評価差・ふりかえりを書く
                                              ↓
                                          ① もう一度集める
```

生徒は**返却を受け取ってから**自己評価（C31）・評価差考察（A34）・ふりかえり（A38）を書く。
したがって**収集は2回行う**。2回目の収集では、AI評価（G列）・AIコメント（H列）・
教師最終評価（I列）を**クラス|出席番号をキーに退避して書き戻す**ので、採点結果は消えない
（保持した人数が収集完了のメッセージに表示される）。行の並び順が変わっても対応は崩れない。

再採点したいときは、メニューの「採点結果をクリア（再採点用）」でG列・H列だけを消してから②を実行する。
