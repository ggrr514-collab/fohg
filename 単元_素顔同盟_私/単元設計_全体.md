# 単元設計書　中学3年 国語
# 「私」を消すもの、「私」を支えるもの
## ――「素顔同盟」（すやまたけし）・「私」（三崎亜記）を批判的に読む

- 学年：中学3年
- 教材：「素顔同盟」（すやまたけし）／「私」（三崎亜記）　※文学的文章・近未来設定の寓話
- 時数：全7時間
- **まとめ活動：グループディスカッション**（話し合いそのものを単元のまとめとする）
- **評価：思考・判断・表現と態度の2観点**（知識・技能はこの単元では評価しない）

# Agent A（設計者）の出力

## 1. 指導要領マッチング

### 教材分析

| | 素顔同盟 | 私 |
|---|---|---|
| 設定 | 仮面着用が法制化された社会 | 住民データが「私」を証明する社会 |
| 「私」を消すもの | 仮面（みんなと同じ笑顔） | データ（置き換え可能な情報） |
| 語り手の位置 | 制度を**疑う**側 | 制度を**運用する**側（「模範とされる市民対応」で5年連続表彰） |
| 語り手の自覚 | ある（息苦しさ・後悔・決意） | **ない**（最後まで気づかない） |
| 結末 | 川を上流へ歩きだす＝行動・希望 | 「どちらが消えようが、同じ『私』なのだ。何の問題もない」＝皮肉 |
| 読者の立ち位置 | 語り手に**寄り添って**読める | 語り手より**多く見えてしまう**（劇的アイロニー） |

この落差が単元の装置である。**「素顔同盟」は語り手に共感させ、「私」は語り手を疑わせる。**その体験そのものが「批判的に読む」ことの学習になる。

### 批判的読みの手がかり（発問・ルーブリックの根拠）

**素顔同盟**
- 先生の論「仮面は私たちに真の平和と自由を与えてくれた」は本文上、完全には否定されていない。擁護の根拠も反論の根拠も本文にある。
- 「素顔同盟」という**名称の皮肉**。仮面を捨てた者がまた「同盟」を組む＝新たな同質集団ではないか。
- 川に浮かぶ仮面は、彼女が自ら捨てた証か、排除された証か。**本文は決めていない。**
- 自然／人工、「橋のない川」、「聖域」という二項対立は、作者が作った枠である。

**私**
- 「解決」「誠意」「対応」「模範的」「正常な状態」がカギカッコ付き。語り手自身が中身の空洞に薄々気づきながら使っている。
- 女性を「無理難題タイプ」「論理矛盾タイプ」と**類型で処理する**ことを、有能さとして語る。
- 中盤で自ら「データがなくなったら『私』も消えるのでは」と想像しながら、自分が二重化されると受容する。
- 図書館の司書の対応は、冒頭の語り手の対応の**鏡**である。

### 指導要領との対応（★思判表1つに限定）

| 区分 | 項目 | この単元での中身 |
|---|---|---|
| **思考力・判断力・表現力等** | **C 読むこと (1)イ**　文章を批判的に読みながら、文章に表れているものの見方や考え方について考えること | 二作にまたがる三つの論題について、語り手の見方を根拠を示して吟味し、結末が肯定するもの・問い残すものを評価する |

**知識・技能はこの単元では評価しない。**発問を廃し、三つの論題への記述に集約したため、語感（(1)イ）を見取る専用の評価材が無くなった。観点別評価は単元ごとに3観点を揃える必要はなく、学期・年間で網羅すればよい。語感は第3時に「解決」「誠意」「模範的」「正常な状態」を扱って**指導はする**が、**評価は次単元（または定期テスト）で行う**。指導案には評価する単元名を明記すること。

- 言語活動：C(2)イ（詩歌や小説などを読み、**批評したり、考えたことなどを伝え合ったりする活動**）── 本単元は後半の「伝え合う」に重心を置く
- **話し合いは言語活動（方法）として位置づけ、指導事項は立てない。**したがって単元目標の述部も「話し合う」ではなく「考える」とした。A 話すこと・聞くこと(1)オ を指導事項に立てて2領域単元にする選択もあるが、7時間では厚くなるため本案では採らない

> **確認をお願いする箇所**：C(1)イ と C(2)イ の文言はこのとおりだが、A(1)オ の第3学年の文言は「進行の仕方を工夫したり互いの発言を生かしたりしながら話し合い、合意形成に向けて考えを広げたり深めたりすること」だと思われる（第1・2学年は別の言い回し）。本案では指導事項に立てないので支障はないが、2領域単元に変える場合は**告示または教科書会社の指導書で確認**すること。
- 生徒は各250字×3本と200字を書くが、これは**読みの記録**であり、B 書くことの指導事項は立てない
- 校内フレームとの接続：「読みの観点」9観点の中から**生徒が自分で選ぶ**（詳細は §2.5）。教師が指定するのは第3層**批評・評価**の1つだけ。深さは**3（自分の考えをもつ）**を目標段階とする。

### ★ 単元目標（1文）

> **自分で決めた観点から二つの作品を批判的に読みながら、三つの論題について、文章に表れているものの見方や考え方について考えることができる。**

**文言の根拠**：C(1)イ「文章を**批判的に読みながら**、文章に表れているものの見方や考え方**について考える**こと」に合わせた。以前の案は「見方や考え方を**捉えて**」としていたが、「捉える」は第2学年までの水準（中2 C(1)イ「…登場人物の設定の意味などを捉えること」）なので、第3学年の到達である「**について考える**」に直した。また述部を「話し合うことができる」から「考えることができる」に改め、**評価する領域（読むこと）と目標の述部を一致させた**。

## 2. 論題設計（AI防御型）

作品ごとの発問は廃止し、**二作にまたがる三つの論題**に集約した。生徒はこの3つすべてについて、「批評・評価」と自分で決めた観点から考えをまとめる。

### 三つの論題

| | 論題 | 見るもの | 批判の目 |
|---|---|---|---|
| **1** | **仮面とデータは、同じものか** | 「私」を消しているもの | ③ 何と何の対立か |
| **2** | **訴えた人は、救われたか** | 仮面を外した彼女／データを消された女性 | ④ 結末は何を残したか |
| **3** | **この社会を続けさせているのは、誰か** | 友人（素顔同盟）／山中（私） | ② 前提は何か |

**視線が「モノ → 当事者 → 周囲」と広がる。**「私」を消すもの、それに抗った人、それを支えている人。
**3つとも、片方の作品では答えられない。**必ず両方を読み、関係づけないと書けない形にしてある。

※「批判の目①（誰の目か）」は論題を立てていないが、論題2（語り手は彼女／女性をどう見ているか）と論題3（語り手自身も続けさせている一人ではないか）の中で必ず働く。

### 各論題に書くこと（3つとも同じ）

1. **批評・評価として、どう評価するか**（主張1文）
2. **自分の観点から見えたこと**
3. **本文の根拠**（引用。★**両方の作品から**出す）

各250字。**AIコピペ不可の理由**：①は生徒個人の判断、②は生徒が選んだ観点に依存する。同じ論題でも観点がちがえば答えがちがうので、一般的な模範解答が存在しない。

---

### 論題1　仮面とデータは、同じものか

| | 本文の根拠 |
|---|---|
| **同じ** | 仮面は「法令化され、制度として確立された」。データも役所の仕組み。どちらも**本人の同意なく作動する** |
| **ちがう** | 仮面は**外せる**——彼女は「両手で仮面を覆うと、そっとそれを外した」。データは本人が触れられず、消すのも「そちらのデータを復元して、今のデータを削除してもらえないだろうか」と**他人（山中）の手** |

**ねらい**：二項対立が作者の作った枠かどうかを問う（批判の目③）。「どちらも同じでこわい」で止まる回答には「彼女は外せた。データは外せるか」と返す。

---

### 論題2　訴えた人は、救われたか　★この単元の核

**二作に、訴えた女性が一人ずついる。しかもどちらも、作品が結末を書いていない。**

| | 素顔同盟（彼女） | 私（女性） |
|---|---|---|
| 訴えた | 仮面を外した。「その素顔は寂しそうで、悲しみさえたたえていた。そして、美しかった」 | 「消されたのは、私のデータなのです」 |
| どうなった | 「会うことはできなかった」「隔離されているのかもしれなかった」→ 川に仮面が浮く | データを入れ替え →「一字一句変わらない」督促状 →「ああ！　確かに私の名前です！」→ 未納料金を払って帰る |

| | 根拠 |
|---|---|
| **救われた** | 彼女は素顔になり、自分の意志で川を上った。女性は満足して帰った |
| **救われていない** | 彼女はその後どうなったか本文が書かない。女性が受け取ったのは**一字一句変わらない紙**で、実質何も変わっていない。「満足して帰った」ことは救いなのか |

**ねらい**：**「納得した」ことと「救われた」ことは同じか**を問う。二人が完全に対応するので比較が空回りしない。意見が実際に割れるので、偏りがほとんど出ない。

---

### 論題3　この社会を続けさせているのは、誰か

**語り手から目を離させ、脇役を読ませる。**

| | 本文の根拠 |
|---|---|
| **素顔同盟：友人** | 「なぜ？　笑顔のおかげで、僕たちはけんかをしないですんでいるんだろ」／「必死にノートをとっている彼の顔も笑顔だった」／僕の疑問に「奇妙に思うことはないらしく」 |
| **私：山中** | 「え？　……ああ、まあ、いいけどな」——**不審に思いながら従う**／語り手自身「役所の仕事とは、『効率』や『合理性』は最優先されない。……無意味でもやらなければいけない業務」 |

| | 根拠 |
|---|---|
| **制度** | 仮面は法令、データは役所の仕組み。個人に責任はない |
| **個人** | 疑わない友人と、疑いながら従う山中がいなければ、どちらの制度も回らない |

**ねらい**：**悪人が一人もいないのに悪いことが起きる**構造を見せる（批判の目②）。
**注意**：「みんなのせい」「社会が悪い」で終わりやすい。**「では誰が一番止められたか」「本文のどこでそうしているか」**と返す。この歯止めはAIの採点プロンプトにも入れてある。

---

### 指導上の注意（教師向け）
- 論題1：「どちらも同じでこわい」→「彼女は外せた。データは外せるか」
- 論題2：「救われた」「救われていない」どちらでもよいが、**必ず本文の「その後」を確認させる**。素顔同盟は書いていない、私は「一字一句変わらない」と書いてある——この差に気づけるかが分かれ目
- 論題3：「みんなのせい」→「では誰が一番止められたか」

## 2.5 自分で観点を決める活動（主体的な読みの中核）

### 二つの道具を、はっきり分ける

生徒に二つの枠を渡すと混乱する。次のように役割を分けて説明する。

| | 誰が決めるか | 何を決めるか |
|---|---|---|
| **「批判の目」4つ** | 教師（全員共通） | **どう読むか**＝疑い方。鵜呑みにせず根拠を確かめる方法 |
| **「読みの観点」** | **生徒が自分で決める** | **どこを見るか**＝着眼点。一人ひとり違っていい |

この二つは直交する。共通の方法を持ちながら、着眼点は各自が選ぶ。

### 生徒が決めること

- **必修は「批評・評価」の1つだけ。**（思判表の評価材を全員分そろえるため）
- **残りの1〜2個は、9観点の残り8つから生徒が自分で選ぶ。**
  登場人物／設定／構成／視点・語り／表現の工夫／題名／主題／自分に生かす
- **観点は9つの中から選ぶ。生徒が独自の観点を立てることは認めない。**9観点は校内の系統表と接続しており、3年間の積み上げを記録するための共通の枠だからである。
- ただし**どの観点を選ぶかは完全に生徒に委ねる。**教師は「この作品ならこの観点」と誘導しない。

> **教師が「視点・語り」を指定しないこと。**これを◎にすると多くの生徒がそこへ集まり、次の異観点編成が崩れる。〈視点・語り〉を選んだ生徒は、教師が班編成で各班に1人ずつ配置して担保する。

### 異観点編成 —— 10分の協議を成立させる仕掛け

**論題は班で共通。違うのは入口（観点）。**全員が「登場人物」を選べば議論は「閏土はかわいそう」型に平らになる。同じ班に〈視点・語り〉〈表現の工夫〉〈設定〉〈笑顔〉の生徒がいれば、**同じ『素顔同盟』が四通りに見えている状態**から議論が始まる。生徒は「自分しか言えないこと」を持って席に着くので、10分でも議論が立ち上がる。

**班編成の手順**
1. 第1時のおわりに観点を**仮決め**（10分）
2. 第2時のおわりに**確定**。教師が「協議・比較ワーク」の①を回収（または教員シート「協議見取り」E列に転記）
3. 観点がばらけるように班を組む。**同じ観点が班内で重ならないようにする**（6人班なら6観点ちがい）
4. 第4時に班と提案する論題を発表

### 評価上の原則（ここを外すと主体性が壊れる）

> **どの観点を選んだかで評価を変えない。**「視点・語り」を選んだ生徒が有利、「題名」を選んだ生徒が不利になってはならない。評価するのは、**その観点から本文の根拠を示して吟味できているか**である。観点の名前を書いただけで本文と結びついていなければ、条件①は未達とする。

この原則はAIの採点プロンプトにも埋め込み、**「別の観点にしたほうがよい」という助言をAIがしない**よう明示的に禁止している（壁打ち②・見直しの両プロンプトにも同じ歯止めを置いた）。

### 自分の読みを自分で吟味させる仕掛け

第6時のおわり（6ラウンド終了後）に、次の3つを書かせる。これが**態度Aの根拠**と**「見直し」200字の材料**になる。

1. 私の観点だから見えたこと（ほかの人は言わなかったこと）
2. **私の観点では見えなかったこと**（だれの、どの観点から教わったか）
3. それを知って、自分の読みはどう変わったか

2が書けたとき、生徒は自分の読みの枠そのものを吟味したことになる。これがC(1)イの到達点であり、第7時に仕上げる「見直し」200字の中核になる。

## 3. AI活用計画（3場面）

| 場面 | タイミング | 方法 | 教育的意図 |
|---|---|---|---|
| **壁打ち** | 三つの論題を書いたあと（第4時） | 3つの考えをまとめて見せ、根拠の弱点と出そうな反論だけ聞く。代筆禁止。**観点を変える提案はさせない** | 議論に耐える準備 |
| **見直しチェック** | 「見直し」200字を書いた後（第7時） | 3点のチェックだけもらう。書き直させない | 自律的な推敲 |
| **比較** | 提出後（返却時） | AI評価と自己評価のずれを考察する | メタ認知 |

**全場面の原則**：まず自分で書く → そのあとAIに見せる。AIに書いてもらうのではなく、フィードバックをもらう。

**話し合いの最中にAIは使わない。**端末は伏せる。AIは話し合いの「前」と「後」だけに置く。

# Agent B（単元＆評価者）の出力

## 4. 単元計画（全7時間）

**単元のまとめはグループディスカッションそのもの。**評価は「まとめた記述」と「当日の発言」の二つを合わせて出す。

| 時 | 学習内容 | 主な活動 | AI活用 | 評価対象 |
|---|---|---|---|---|
| **1** | 二作を読む | 「あなたが『あなた』であることは何によって証明できるか」→ ゴール（話し合い）を提示 → **批判の目**4つ → 二作を読む（「私」は分量が多いので宿題で通読）→ **観点を仮決め** | — | — |
| **2** | 「素顔同盟」の吟味／観点の確定 | 先生の主張の**擁護の根拠を先に3つ**→ 反論3つ →「『素顔同盟』という題名は何を暗示するか」→ **観点を確定**／教師が回収して班編成 → **比較表の「素顔同盟」側**を埋める | — | 態度（観点と理由） |
| **3** | 「私」の吟味 | カギカッコ付きの語を丸で囲む（語感の指導）→「この人は良い職員か」→ 女性の訴え →「なぜ『何の問題もない』に不安になるのか」→ 司書＝鏡構造 → **比較表の「私」側** → **論題1をまとめる（10分）** | — | — |
| **4** | 論題2・3の準備 | **論題2の考えをまとめる（15分）** → **論題3の主張と引用を決める（15分）** → 壁打ちで点検。**250字にするのは家庭学習**（5時までに3つそろえる） | 壁打ち | **思判表**（3つの記述） |
| **5** | 話し合い **1周目** | **はじめに、その時間の提案者3人と担当論題を発表**。10分×3ラウンド（論題1→2→3） | — | **思判表**（発言）／**態度** |
| **6** | 話し合い **2周目** | 同じく当日に提案者3人を発表。同じ論題1→2→3を、1周目に出た別の観点をふまえて問い直す → **「見えなかったこと」を書く** | — | **思判表**（発言）／**態度** |
| **7** | **まとめのディスカッション** | 代表者パネル①12分・②12分・フロア記録 → **「見直し」200字を仕上げる** | 見直しチェック | **思判表**（記述の総括） |

> **時間の実際が、ここだけ厳しい。**3つの論題はすべて二作にまたがるので、**両作を読み終えるまで1本も書けない**。だから準備は第3時以降に集中する。250字×3本＝750字を授業内で書き切るのは無理なので、**第3時に論題1（10分）、第4時に論題2（15分）と論題3の骨組み（15分）を教室で作り、250字への文章化は家庭学習**とした。第5時の冒頭までに3つそろえる。
>
> 考える作業は教室に残し、文章化だけを家に出す形である。二作比較表は6行あるが**★の4行が必須**で、これが3つの論題の材料になる（★1→論題1、★2→論題2、★3→論題3）。「私」（約4,000字）は第1時の宿題で通読させ、第3時の冒頭で確認する。

### 三つの論題（すべて二作にまたがる）

| | 論題 | 見るもの |
|---|---|---|
| **1** | 仮面とデータは、同じものか | 「私」を消しているもの |

### ★ 発表する論題は当日に知らせる

生徒は**3つすべてを準備しておく。**誰がどの論題で提案者になるかは、**第5時・第6時のはじめに教師が発表する。**

| ねらい | 効果 |
|---|---|
| 3つ全部を準備する必然性が生まれる | 「自分の担当だけ読む」が成り立たない |
| どの論題の検討でも自分の考えを持って参加できる | 提案者以外の6分間が受け身にならない |
| 二作を通して読む必要が生まれる | 3論題すべてが両作にまたがるため |

### 協議の仕組み（第5・6時）

**1ラウンド10分**

| 時間 | 動き |
|---|---|
| 0:00–2:00 | **提案者**が話す（**自分の観点**＋主張1文＋本文の根拠2か所） |
| 2:00–8:00 | **検討**。他のメンバーは全員、**自分の観点から**質問か反論を1回以上 |

**常設3役割（毎ラウンド時計回りに交代）**
- **引用チェック係**…「本文のどこ？」を必ず1回
- **疑い係**…「しかし／とはいえ」で始まる発言を必ず1回
- **記録係**…主張と到達点を1行ずつ

「疑い係」は、批判的に読むことを生徒の性格任せにせず**役割として制度化**する装置である。生徒用ワークシートでは「話し合いワーク」③に置いた。

### 評価材：記述と発言の二本立て

**話した言葉は残らない。**だから評価を二つに分け、両方を合わせて確定する。

## 6. 評価規準と判断の目安

**この単元で評価するのは思考・判断・表現と態度の2観点。**知識・技能は指導のみで、評価は別の単元で行う。ただし**指導案・評価基準シートには参考として掲載する**（指導事項の系統が見えるようにするため）。

評価は二層で書く。**評価規準**（指導事項を「〜している」に変換した一文）を立て、その下に**判断の目安**を置く。

### 【参考】知識・技能　(1)イ　語感を磨き語彙を豊かにする　＜本単元では評価しない＞

> **評価規準：語句の意味や働きに注意して文章を読むことを通して、語感を磨き語彙を豊かにしている。**

**第3時に指導のみ行う。**「私」のカギカッコ付きの語（「解決」「誠意」「模範的」「正常な状態」）を丸で囲ませ、その働きを扱う。評価材となる専用の記述を設けていないため、この単元では評価しない。評価する場合は、語の働きを説明させる記述欄を別途設けること。

| 段階 | 判断の目安 |
|---|---|
| **A** | 選んだ語の働きを、**語り手の立場（制度を運用する側）と結びつけて**説明している。例「『解決』とは相手が満足することであって、問題が解決することではない、と語り手自身が知っている」 |
| **B** | その語が「**言葉だけは立派で中身が空**」と示すことを説明し、自分の経験を挙げている |
| **C** | 語を挙げるだけ、または経験を挙げるだけ |

### 思考・判断・表現　C 読むこと(1)イ　＜この単元で評価する＞

> **評価規準：「読むこと」において、文章を批判的に読みながら、文章に表れているものの見方や考え方について考えている。**

**評価材：三つの論題の記述＋当日の発言＋「見直し」200字**

| 段階 | 判断の目安 |
|---|---|
| **S** | ①②に加え、他の観点を受けて考えを見直し、**自分の観点では見えなかったこと**に触れて今の考えを述べている |
| **A** | **条件①②の両方**。三つの論題すべてを観点と本文の根拠でまとめ、各論題で両作品に触れ、当日も自分の観点から根拠を示して発言した |
| **B** | ①②の**一方だけ**。準備はあるが発言が根拠に届かない、または発言はよいが3つそろっていない |
| **C** | 準備が1〜2論題だけで本文の根拠がない、または発言していない |
| **D** | 準備がほとんどない |

> **どの観点を選んだかで評価を変えない。**「視点・語り」を選んだ生徒が有利、「題名」を選んだ生徒が不利になってはならない。

**AIの暫定評価だけで確定しないこと。**AIは記述しか見ていない。当日の発言が×の生徒は、記述がSでもA以上にはならない。

### 主体的に学習に取り組む態度　＜この単元で評価する＞

> **評価規準：積極的に文章を批判的に読み、学習課題に沿って、考えたことを互いに伝え合おうとしている。**

**評価材：観点と選んだ理由（2時）・記録係シート・「見えなかったこと」（6時）・フロア記録**

| 段階 | 判断の目安 |
|---|---|
| **A** | 自分が選んだ観点で二作を読み通そうとし、**他の観点からの指摘を受けて自分の読みを見直し、書き直している**（＝自らの学習を調整しようとする側面） |
| **B** | 自分が選んだ観点で読み、話し合いに参加して自分の考えを述べている（＝粘り強い取組を行おうとする側面） |
| **C** | 観点が決まらない、または話し合いに参加していない |

> **「3つそろっているか」は態度では見ない。**提出の有無は形式要件であり、態度は「①粘り強い取組を行おうとする側面」と「②自らの学習を調整しようとする側面」で見る。準備がそろっているかは**思考・判断・表現の条件①だけ**で判断し、同じ事実で2観点を決めないようにした。

### ★ 観点別評価への読みかえ

**観点別学習状況の評価はA・B・Cの3段階**（評定が5段階）。本単元のS〜Dは生徒への返却とルーブリックの細かさのために用いるもので、指導要録へは次のように読みかえる。

| 本単元の段階 | 観点別学習状況の評価 |
|---|---|
| **S ・ A** | **A**（十分満足できる） |
| **B** | **B**（おおむね満足できる） |
| **C ・ D** | **C**（努力を要する） |

生徒への返却はS〜Dのまま行う。この対応表は生徒用「評価基準」シートと教員用「AI設定」シートにも載せてある。**知識・技能と態度はもともとA・B・Cなので、そのまま転記する。**

## 7. 解答例（全段階・生徒の文体）

観点「表現の工夫」を選んだ生徒の例。**どの観点を選んだかでは差がつかない**ことも示す。

### 【論題1への記述／A相当】

> 私は「表現の工夫」の観点で読んだ。**仮面とデータは同じではないと考える。**『素顔同盟』の仮面は「その無個性な笑顔はみんなと同じなのだ」と**形が言葉で説明されている**。だから彼女は「両手で仮面を覆うと、そっとそれを外した」ことができた。『私』のほうは「解決」「誠意」「模範的」がカギカッコに入れられていて、**中身が見えない書き方**になっている。データも同じで、消すのも「削除してもらえないだろうか」と他人の手だ。**自分で外せるものと、自分では触れないもの。**この差は大きい。

→ 主張1文あり／両作品から引用あり／観点（言葉の書かれ方）から根拠を出している。**A相当**

### 【論題2への記述／A相当】

> **私は、どちらも救われていないと考える。**『私』の女性は「ああ！　確かに私の名前です！」と喜ぶが、その督促状は「一字一句変わらない」と書かれている。**言葉の上では何も変わっていない**のに、本人だけが変わったと思っている。『素顔同盟』の彼女は自分で仮面を外したが、そのあとは「会うことはできなかった」「隔離されているのかもしれなかった」で、**作品が書いていない**。書かれていないことは、救われた証拠にならない。

→ 「納得した」ことと「救われた」ことを切り離せている。両作から引用あり。**A相当**

### 【論題3への記述／A相当】

> **続けさせているのは、疑わない人たちだと考える。**『素顔同盟』の友人は「なぜ？　笑顔のおかげで、僕たちはけんかをしないですんでいるんだろ」と言い、僕の疑問を「奇妙に思うことはないらしく」流す。『私』の山中は「え？　……ああ、まあ、いいけどな」と、**不審に思いながら従っている**。ここが怖い。山中は気づいているのに止めない。制度は法令で決まっているけれど、**止められる場所にいた人が止めなかった**から続いている。

→ 「みんなのせい」で止まらず、**誰が・本文のどこで**まで示している。**A相当**

### 【見直し200字／S相当】

> 私は論題2で、どちらも救われていないと主張した。『私』の督促状が「一字一句変わらない」ことと、彼女のその後が書かれていないことを根拠にした。
> 　**しかし**、話し合いでCさんが「設定」の観点から「彼女は川を上流へ歩きだした。行き先があるのは救いではないか」と言った。**私は「表現の工夫」で言葉の書かれ方ばかり見ていて、彼女が動いたことを見ていなかった。**
> 　いま私は、女性は救われていないが、彼女は**救われる側に行こうとした**とまでは言えると考えている。

→ ①（3論題＋根拠）②（当日の発言が○）③（見えなかったこと＋今の考え）すべて。**S**

### 【B】準備はあるが発言が届かない型

> 3つの論題すべてに主張と引用を書いている。しかし当日の発言は「私も同じだと思います」「たしかにそうですね」だけで、自分の観点と本文の根拠を出さなかった。（協議見取りH列＝△）

→ 条件①はA相当だが、**条件②が未達**。**B止まり**。記述だけを見たAIはAを返すので、**教師がJ列で下げる。**

### 【B'】発言はよいが準備がそろわない型

> 当日は「表現の工夫」の観点から本文を引いて鋭く発言した（H列＝○）。しかし記述は論題1と2だけで、論題3が空欄。

→ 条件②はA相当だが、**条件①が未達**。**B止まり**。AIも3つそろっていないのでBを返す。

### 【C】論題3でよくある型

> 「続けさせているのは社会だと思う。みんなが仮面をつけているから、やめられない。データも同じで、社会がそうなっているから仕方ない。」

→ **誰が・本文のどこでそうしているかが無い。**「みんな」「社会」で止まっている。引用もない。**C**。指導では「友人は何と言ったか」「山中はどう答えたか」と本文に戻す。

### 【D】

> ほとんど記入がない。

→ **D**

## 9. 授業者向け・運用上の注意

1. **端末は協議中は伏せる。**提案メモは第4時に紙へ転記しておく。画面を開いたまま協議すると顔が上がらない。
2. **AIが採点するのはD〜G列（3論題＋見直し）だけ。**知識・技能はこの単元では評価しない。
3. **当日の発言は「協議見取り」H列（○△×）で必ず記録する。**これが思判表の条件②であり、態度の評価材でもある。ここが空だと**A評価をつける根拠が無くなる**（条件①だけではB止まり）。第5・6時は巡回しながらF〜J列を埋める。全発言を聞き取る必要はなく、提案者の2分と、その生徒が本文を引いたかどうかだけ見れば足りる。
4. **配付・提出はGoogleスプレッドシート形式で行う。**xlsxのまま提出されても収集と採点はできる（Apps Scriptの「サービス」で**Drive API（v2）**を有効化しておくこと）が、**評価の返却（ステップ3）はできない**。収集時に「xlsx形式が何人分あるか」と警告が出るので、該当者には再提出させる。
5. **最終評価はJ列で確定する。**AIのH列は記述だけを見た暫定値で、当日の発言を見ていない。「協議見取り」H列が△や×の生徒は、記述がSでもA以上にしない。J列に値を入れてから③を実行すると、AI評価ではなくJ列の値が生徒に返る。食い違う場合は生徒に返るコメントの冒頭に「評価は先生が確定しています」と自動で注記が入る。採点エラーの文言は生徒に返らない。
6. **組と出席番号は必ず入力させる。**返却先はこの2つで特定している。どちらかが空の提出物は収集時にスキップされ、ファイル名とともに警告が出る。
7. 40人を超える学級では `CONFIG.DATA_END` と教員シートのデータ行を増やす。
8. **観点は第2時のおわりに必ず回収する。**ここで回収しないと第5時の異観点編成ができず、協議が平らになる。回収は紙でもよい（教員シート「協議見取り」E列に転記）。**同じ観点が班内で重ならないように組む。**
9. **「その観点では読めない」と言わない。**9つのどれを選ぶかは生徒に委ねる。返すのは「その観点から、本文のどこがそう言わせるのか」だけにする。
10. **観点が偏ったとき**は班編成で散らして対応する。「別の観点にしなさい」と選び直させない。どうしても重なる場合は、同じ観点の2人に別の論題の提案者を割り当てる。
11. **話し合いの最中は端末を伏せる。**提案メモは第4時に紙へ転記しておく。AIは話し合いの「前」と「後」だけに置く。
12. **「見直し」200字を長くしない。**14分で書き切る量にしてある。長くすると作文に戻り、まとめが話し合いでなくなる。
13. **発表する論題は当日まで伝えない。**先に伝えると、生徒は担当分しか準備しなくなる。3つ準備させることが、二作を通して読ませる仕掛けである。第5時・第6時の冒頭3分で配る。
14. **6ラウンド分の割り当ては2時間分まとめて先に組む。**当日に即興で決めると、2時間で全員が1回にならない。

### 運用の順序（ここを間違えると手戻りになる）

```
① 集める  →  ② 採点する  →  ③ 返す  →  生徒が自己評価・評価差・ふりかえりを書く
                                              ↓
                                          ① もう一度集める
```

生徒は**返却を受け取ってから**自己評価（C31）・評価差考察（A34）・ふりかえり（A38）を書く。
したがって**収集は2回行う**。2回目の収集では、AI評価（G列）・AIコメント（H列）・
教師最終評価（I列）を**クラス|出席番号をキーに退避して書き戻す**ので、採点結果は消えない
（保持した人数が収集完了のメッセージに表示される）。行の並び順が変わっても対応は崩れない。

再採点したいときは、メニューの「採点結果をクリア（再採点用）」でG列・H列だけを消してから②を実行する。
