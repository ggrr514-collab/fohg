## 3. 商品設計

### 3-1. 原則: 「量」と「段階」

- 1レベル = 30枚 = 30日。1日1枚を守る
- 全体で **300枚**を目標にし、初回から一気には出さず、毎月追加する
- 「たくさん模写する」ために1枚を軽くする。解説は1〜2行、動画なし、印刷して描くだけ

### 3-2. 3段階（すべて「形」）

| レベル | 狙う力 | 課題 | 枚数 |
|---|---|---|---|
| **基礎**（全画風共通） | 線、形、比率 | 直線・曲線・円 → 図形の組み合わせ → シルエット模写 → グリッド模写 → 基準線2本 → グリッドなし | 50枚 |
| **発展**（画風別） | 部分、角度、比率。向きが変わっても崩れない | 部分模写（目・鼻口・耳・手・髪・服） → 顔の角度（正面・斜め・横・あおり） → 頭身・全身 → 見方を変える（逆さ模写・ネガティブスペース・一本線の輪郭・拡大・鏡像） → 2分クロッキー → 記憶 | 30枚/画風 |
| **応用**（画風別） | 速さ、記憶、転用 | 時間制限クロッキー → 記憶模写 → 三分割グリッド → 角度を変えて描く → 差し替え → 合成 → 自分のキャラで同じ構図 | 30枚/画風 |

基礎は画風を混ぜる（1枚ごとに違う画風のお手本）。**基礎を描くうちに好きな画風が分かり、発展でその画風を選ぶ**流れになる。これが「選べる」の入口。

### 3-3. 選べる画風（発売順）

| 順 | 画風パック | 中身 | 備考 |
|---|---|---|---|
| 1 | アニメ・マンガ | 顔、髪、手、全身、服のしわ | 需要最大。初回発売 |
| 2 | ゆるかわ・デフォルメ | 動物、食べ物、小物、人 | 中高生・手帳層 |
| 3 | ロゴ・レタリング | 手描き文字、オリジナルロゴ、装飾罫、アイコン | **実在ロゴは使わない**（商標・著作権）。お父さんが作ったオリジナルロゴ30点 |
| 4 | リアル・写実 | 静物、手、顔のパーツ、動物 | 比率・輪郭の練習に最適 |
| 5 | レトロ・ポップ | 昭和レトロ、ポップアート風 | 2026年の書籍トレンド（「レトロモダンなイラスト練習帳」） |
| 6 | 背景・小物 | 建物、植物、家具、パース | 上級需要 |

初回はアニメ・マンガ1画風。以後、毎月1画風（30枚）を足す。全6画風がそろうまで約6か月。

### 3-4. 「選べる」仕組み

BOOTH は「1点ずつ選んで束ねる」ことができないので、次の2段で対応する。

1. **専用ページに「選び方」を置く。** 3問（描きたいもの / 今できること / 1日にかけられる時間）に答えると、買うべきパックと BOOTH リンクが出る
2. **SKU は「基礎」＋「画風別パック」＋「セット」**に絞る。組み合わせは購入者が選ぶ

### 3-5. 1枚のワークシート（全レベル共通）

1. **お手本**（手描き）
2. **なぞり枠**（薄グレー。基礎は必ず、発展以降は任意）
3. **自力模写枠**（グリッド有り/無しを選べる）
4. **記憶模写枠**（発展以降）
5. **自己チェック**（3〜5項目。例:「縦横比は合っているか」「一番暗い場所はどこか」「線の強弱はどこで変わるか」）
6. **今日のポイント**（1〜2行）
7. **枚数番号と進捗マス**（30マスを塗る）

A4 縦、余白 15mm 以上。家庭用プリンタの白黒印刷で下絵が見える濃度にする。

### 3-6. 補助の減らし方（白黒・線画のみ）

同じ「形を取る」でも、補助を段階的に外す。

| 段階 | 補助 | 目的 |
|---|---|---|
| なぞる | 薄グレーの下絵 | 手に角度と長さを覚えさせる |
| グリッド 4×4 | マス目 | マスごとに通過点を見る |
| 基準線 2本 | 十字だけ | 比率を自分で測る |
| グリッドなし | なし | 目測 |
| 記憶で描く | お手本を隠す | 形を内部化する |
| 逆さ・鏡像・ネガティブスペース | 見方を変える | 思い込みを消して純粋に形を見る |

- 基礎: なぞる → グリッド → 基準線 → なし
- 発展: グリッド → 基準線 → なし → 記憶。後半で見方を変える課題
- 応用: なし → 記憶 → 時間制限 → 転用
- **カラー版**は将来の任意オプション（線画にお手本の色を塗る「ぬり見本」）。本体の練習には含めない

### 3-7. 「育つ教材」

- 商品ページのファイルを毎月追加する（BOOTH の「ファイルの追加・管理」で追加できる。購入者は何度でも再ダウンロード可）
- 「買った後も増える」を商品説明に明記する。hide channel の月刊方式との差になる
- 追加のたびに SNS で「今月の30枚」を告知 → 既存購入者の再訪と新規の両方を取る

### 3-8. 同梱物

- 使い方（1枚）: 30日の回し方、印刷設定、コンビニ印刷
- 30日カレンダー
- 1日目・30日目の比較シート（投稿しやすい形）
- 自己評価ルーブリック（3段階）
- 「うまく描けない」原因診断（比率か、線か、角度か、思い込みか）

## 4. 制作方針

> **v3.1 追記（2026-09-23）:** 初回のお手本は AI 作成の手描き風線画（SVG）で用意した。商品説明では「手描き風の線画データ（AI で作成、1点ずつ確認）」と表記する。手描きに差し替えた分は同番号の PNG で上書きでき、その時点で表記を戻す。

### 4-1. 原則

- **お手本は手描き、または AI 作成を明記。** 商品説明に実態を明記する
- 生成 AI は次に限定: ワークシート枠の生成、なぞり線の淡色化、モチーフ案の洗い出し、難易度順の並べ替え、解説文の下書き
- ロゴ・レタリングは**オリジナル**のみ。実在ロゴ・書体の丸写しは素材にしない

### 4-2. 工程

1. モチーフをレベル×画風でリスト化（初回 80 点、予備 20 点）
2. 描く（1枚 30〜60分）
3. スキャン → 線画整理 → 淡色化（なぞり枠用）
4. 枠にはめる → 印刷テスト → 検品
5. 印刷用 PDF を書き出し、家庭用プリンタで試し刷り

### 4-3. 初回の作画量

| 内容 | 枚数 | 作画時間の目安 |
|---|---|---|
| 基礎ドリル | 50 | 25〜50時間 |
| 発展・アニメマンガ | 30 | 20〜30時間 |
| 無料お試し版（上記から抜粋） | 8 | 0 |
| **合計** | **80** | **45〜80時間** |

週 10 時間なら 5〜8 週間。以後は月 30 枚（15〜30 時間/月）。

## 付録A 練習設計: 模写のコツと、それをやらせる仕組み

「コツを教える」のではなく「コツを踏まないと1枚が終わらない」構造にする。
解説は読まれないので、枠・チェック・順番で強制する。

### A-1. 踏ませる10のコツと、シート上の仕組み

| # | コツ（模写で伸びる人がやっていること） | 仕組み（シートのどこで強制するか） |
|---|---|---|
| 1 | **今日は何を盗むか1つ決める。** 目的のない模写は上がらない | 「今日のポイント」を1行で固定（例:「顔の縦横比だけ合わせる」）。チェック項目もその1点に絞る |
| 2 | **大→小の順で描く。** 全体のシルエット・比率 → 大きな塊 → 細部 | 自力枠の上に「①外形 ②大きな塊 ③細部」の小さな3コマ手順を印刷。基礎では①だけで終わる課題を入れる |
| 3 | **測る。** 縦横比、目測の基準線、水平・垂直、ネガティブスペース | 基礎はグリッド付き枠。中盤で「2本の基準線だけ」、後半でグリッドなし。「比率メモ欄」に「縦:横= : 」を書かせる |
| 4 | **線は迷わず1本で。** 毛羽立った線を重ねない | なぞり枠を「1回だけなぞる」指示に。線の課題では「引き直し禁止」の注記。線の強弱は「太い所に○」を付けてから描く |
| 5 | **見方を変えて思い込みを消す。** 逆さ・鏡像・隙間 | 発展後半に逆さ模写・鏡像模写・ネガティブスペース・一本線の輪郭を置く。「顔」ではなく「線と形」として見る |
| 6 | **描いたら比べて直す。** 並べる、重ねる、反転する、離れて見る | チェック欄の1項目目は必ず「お手本と並べて、ずれた場所に○」。透ける紙で重ねる方法を「使い方」に記載 |
| 7 | **記憶で描き直す。** 見ながら描けるだけでは身につかない | 発展以降は「記憶模写枠」を必ず置く。お手本を折って隠せるように、お手本を用紙の端に配置 |
| 8 | **時間を区切る。** 長時間の1枚より、短時間の複数枚 | 各枠に目安時間を印刷（なぞり3分 / 自力10分 / 記憶5分）。応用では「2分クロッキー枠×3」の課題を入れる |
| 9 | **間隔をあけて同じものをもう一度。** | 30枚のうち Day 1・15・30 は同じモチーフ。比較シートに3枚を貼る |
| 10 | **1つ言葉にして終わる。** 「気づき」を書くと次に残る | 最下段に「今日の気づき（1行）」。空欄だと進捗マスを塗れないルールにする |

### A-2. レベルごとの重心

| レベル | 特に効かせるコツ | 難易度の上げ方 |
|---|---|---|
| 基礎 | 2 大→小、3 測る、4 線 | 線の本数、左右対称の有無、重なりの有無、グリッドの細かさ |
| 発展 | 3 測る、5 見方を変える、6 比べて直す、7 記憶 | 部分の細かさ、顔の角度、頭身の数、補助の少なさ |
| 応用 | 1 目的、8 時間、9 反復、転用 | 制限時間、構図、「お手本を変えて描く」の変え幅 |

### A-3. 角度と向き（発展の中心）

| コツ | 仕組み |
|---|---|
| 十字を先に引く。斜めなら中心線を曲げる | 角度課題は「基準線2本」の枠。チェック1項目目は「中心線はカーブしているか」 |
| 奥の幅は「比」で書く | 斜め課題に「縦:横」「奥:手前」のメモ欄 |
| 向きが変わっても頭身は同じ | 全身課題は頭身を数えてから線を入れる |

### A-4. 転用（「模写止まり」を防ぐ）

模写だけでは自分の絵が描けない、という定番の失敗を避けるために、応用の各週に「変えて描く」課題を1枚入れる。

- 角度を変える（正面のお手本を斜めに）
- 一部を差し替える（髪型・持ち物・表情）
- 2つのお手本を合成する（Aのポーズ＋Bの服）
- 自分のキャラで同じ構図を描く

### A-5. 「うまくいかない」診断（同梱）

| 症状 | 原因 | 戻る課題 |
|---|---|---|
| 全体が縦長・横長になる | 比率を測っていない | 基礎のグリッド課題 |
| 線がガタガタ・毛羽立つ | 線を重ねている、手首で引いている | 基礎の直線・曲線課題（1回線） |
| 斜め・横向きになると崩れる | 中心線を曲げていない、奥の幅を測っていない | 発展の角度課題（十字を先に、奥の幅を比で） |
| 見ながらなら描けるが、離すと描けない | 記憶模写をしていない | 発展の記憶模写枠を毎日 |
| それらしく描けるが重ねるとずれる | 思い込みで描いている | 逆さ模写・ネガティブスペース |
| 模写はできるが自分の絵が描けない | 転用課題をしていない | 応用の「変えて描く」 |
