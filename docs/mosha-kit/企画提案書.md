## 0. 前提と結論

**前提**
- 販売主体は YouTube チャンネル「おえかきお父さん」（お父さんと子どもが一緒に描いて遊ぶチャンネル）。
- お手本は「お父さんが描いた絵」であることが商品価値の核。生成AIツールの無料配布（Fohg）とは別物として設計する。
- 登録者数・再生数はこちらから取得できなかった（YouTube が遮断されているため）。販路の一部はこの数字で変わるので、5章で分岐を示した。
- 「模写」はイラストの模写と解釈した。

**結論（推奨案）**

| 項目 | 推奨 |
|---|---|
| コンセプト | 「お父さんと一緒に、30日で"見て描ける"になる模写ドリル」 |
| 最大の差別化 | ①チャンネルの動画と1枚ずつ連動（QRで「この1枚をお父さんが描く動画」へ飛ぶ）②基礎→発展→応用の一本道 ③同じ絵で白黒→カラーへ進む |
| メインターゲット | チャンネル視聴者＝小学生とその親。「親子で一緒に描く」前提で設計 |
| サブ | 大人の描き始め層（同じ素材を「大人版」の解説で出し直す） |
| 販路 | YouTube 概要欄・固定コメント → BOOTH（初動）。登録者1,000人以上なら BASE を YouTube ショッピングに連携 |
| 価格帯 | 各パック880〜1,280円、3段階セット2,480円、親子まとめ買い割引 |
| 制作方針 | お手本は手描き。AI はレイアウト・ワークシート枠の生成・原稿整理の補助に限定し、お手本には使わない |

## 1. 競合分析

### 1-1. 直接競合（模写・描き込み式の練習教材）

| 商品 | 販路 | 価格 | 分量 | 強み | 弱み（＝こちらの隙） |
|---|---|---|---|---|---|

| 季月エル「トレス＆模写を使った練習術」 | BOOTH | 500円 | 62ページ | 方法論が明確、低価格 | 解説本で練習素材が少ない。2018年刊 |
| ホビージャパン「線の描き方ドリル」 | 書店/Kindle | 1,980円 | 128ページ | 薄グレーのなぞり線→本番線の二段構え。直線→曲線→顔→全身の段階設計 | 白黒の「線」だけで終わる。色・陰影に進めない |
| 成美堂「描きこみ式 ゆるっとかわいいイラスト練習帳」 | 書店 | 1,100円 | 159ページ | お手本＋練習スペース、動物・人物を網羅 | 段階設計が薄い。動画連動なし |
| 大泉書店「マンガデッサン練習ドリル 基本編」 | 書店 | 990円 | 96ページ | 30日構成、なぞるだけで練習になる | 2017年刊。カラーなし |
| JTB「推しかわ♡イラストレッスン」（ばななふぃっしゅ協力） | 書店 | 書籍 | 小学生女子向け | 登録者22万人の YouTuber の知名度、子ども向けに特化 | 「かわいく描く」寄りで、観察して形をとる練習ではない |

### 1-2. 間接競合・代替手段

| 種類 | 例 | こちらへの影響 |
|---|---|---|
| 無料プリント | ちびむすドリル（運筆・お絵かき）、学習プリント.com「まねして描いてみよう Step1/2」 | 幼児〜低学年向けは無料が強い。**「無料プリントの上」に置く理由が要る** → 動画連動・段階設計・親子の声かけ |
| お絵かき講座 YouTube | パルミー、ばななふぃっしゅ（ショート中心）、しばさき先生 | 知識は無料で見られる。売れるのは「用意された練習環境」と「お父さんと一緒に」という体験 |
| アプリ | シンプルトレース、MediBang | デジタルで描く子には印刷不要の PNG 版が要る |
| 添削サービス | ココナラ（500円〜） | 個別添削は真似しない。代わりに「親子で見る自己チェック表」で近い価値を出す |
| AI 塗り絵（Kindle） | 多数 | 飽和・価格競争・低評価。「塗るだけ」「誰が描いたか分からない線画」は選ばれない。**手描き＋作者の顔が見える**のが強み |

### 1-3. ポジショニングの空白

競合を「段階設計」「動画連動」「親子向け」の3軸で見ると、3つを同時に満たす商品はない。

- hide channel: 動画連動○ 段階×  親子×
- 線の描き方ドリル: 段階○ 動画× 親子×
- 無料プリント: 親子○ 段階△ 動画×
- 推しかわレッスン: 親子○ 動画△ 段階×

「**動画で一緒に描ける × 段階式 × 親子**」を取る。

### 1-4. 競合から借りる「守るべき型」

- 薄いグレーの下絵をなぞる→隣の枠に自力で描く（線の描き方ドリル）
- 「30日」の区切り（マンガデッサン練習ドリル）。動画のシリーズ化とも噛み合う
- お試し版を無料の別商品にする（hide channel「お試し版」）
- タブレット用の軽量版と印刷用の高画質版を分ける（季月エル）

## 3. 商品設計

### 3-1. 3段階カリキュラム

各レベルは「30枚＝30日分」を基本単位とし、**1枚につき1本の動画**（お父さんがその絵を描く様子）を対応させる。

| レベル | 狙う力 | 課題の中身 | モチーフ | 対応動画の型 |
|---|---|---|---|---|
| **基礎** | 線を引く、形をとる、比率 | 直線・曲線・丸 → 図形の組み合わせ → シルエット模写 → 4分割グリッド模写 | 果物、乗り物、単純な動物、おもちゃ | 3〜5分。お父さんが描きながら「ここ見て」と言う |
| **発展** | 立体、明暗、構造 | 明暗3段階 → 5段階グレースケール → 光の向きを変えた同じモチーフ → 部分模写（顔パーツ、手、しっぽ・羽） | 動物、人物バストアップ、静物の組み合わせ | 5〜8分。子どもの描いたものと比べる回を入れる |
| **応用** | 構図、色、自分の絵にする | 三分割グリッド模写 → 3色限定の色模写 → フルカラー模写 → 記憶模写 → 「お手本を変えて描く」 | 人物全身、複数モチーフ、簡単な背景 | 8〜10分。親子で「変えて描く」を実演 |

### 3-2. 1枚のワークシートの構造（全レベル共通）

1. **お手本**（お父さんの手描き）
2. **なぞり枠**（薄いグレーの下絵。基礎は必ず、発展以降は任意）
3. **自力模写枠**（グリッド付き/無しを選べる）
4. **記憶模写枠**（お手本を隠して描く。発展以降）
5. **親子チェック**（3〜5項目。親が読み上げて子が答える形。例:「いちばん大きい丸はどこ？」「いちばん暗いのはどこ？」）
6. **QR コード**（この1枚の動画へ）
7. **できたシール欄**（30枚分の進捗が1枚の表で見える）

A4縦、余白15mm以上、家庭用プリンタでの白黒印刷でも下絵が見える濃度に調整する。

### 3-3. 白黒版とカラー版

同じモチーフ番号で白黒とカラーを対応させ、「白黒で形と明暗をつかむ → 同じ絵をカラーで塗る・色を写す」と連続させる。

| 版 | 内容 | 目的 | 子ども向けの見せ方 |
|---|---|---|---|
| 白黒・線画 | 線のみ | 形と比率 | 「なぞって、となりに描く」 |
| 白黒・グレースケール | 3〜5段階の明暗 | 立体と光 | 「濃い・ふつう・うすい を見つける」 |
| カラー・ぬりえ | 線画に自分で塗る | 色を選ぶ体験 | 「お父さんと同じ色にしてみよう」 |
| カラー・3色限定 | 3色までの色模写 | 配色 | 「3本だけで描く」 |
| カラー・フルカラー | 完成イラスト | 色模写 | 応用のみ |

基礎は白黒＋ぬりえ、発展でグレースケール、応用でフルカラー。
カラー版は「カラー追加パック」として単独でも買えるようにファイルを分ける。

### 3-4. バリエーション展開（初回リリース後）

- モチーフ別パック: 動物 / 乗り物 / 人物 / 食べ物 / 背景
- 大人版: 同じお手本に「大人向けの解説とチェック表」を差し替えたもの
- 季節版: 年賀状、ハロウィン、母の日・父の日カード（親子のイベントと結びつく）
- 形式別: 印刷用 PDF、タブレット用 PNG（1枚ずつ）、ぬりえ用の線画だけの PDF
- 紙版: ペーパーバック（Kindle）またはコンビニプリント連携（後述）

### 3-5. 教育設計（教員としての強みを出す部分）

- **学習ループ**を毎枚に埋め込む: 見る → なぞる → 自力で描く → お手本と並べて比べる → 直す → 記憶で描く
- **親子チェック**が「添削」の代わり。親が絵を描けなくても、質問を読むだけで観察のポイントを教えられる
- **30日カレンダー**と**1日目・30日目の比較シート**を同梱。比較を投稿してもらう
- 「うまく描けない」の原因診断ページ（比率か、線か、明暗か）を親向けに用意
- 動画の中でお父さんが「失敗して直す」場面を残す。子どもは「上手い人の完成品」より「直す過程」から学ぶ

## 4. 制作方針（手描きと AI の線引き）

### 4-1. 原則

- **お手本は全部お父さんの手描き。** これが商品の信頼であり、チャンネルとの一貫性でもある
- 生成 AI は次の用途に限定する
  - ワークシートの枠・レイアウト・QR・チェック表の生成
  - 薄グレーのなぞり線の自動生成（お手本をスキャンして淡色化）
  - モチーフ案の洗い出し、難易度順の並べ替え、解説文の下書き
- 商品ページに「お手本は手描き、レイアウト制作にツールを使用」と書けば説明がつく

### 4-2. 理由

- 絵描き界隈・保護者層ともに「AI 生成のお手本」への警戒がある。チャンネルの信用に関わる
- AI 画像は手指や構造が破綻しやすく、破綻した絵を模写させると教材として致命的
- 手描きなら著作権が明確で、転載への対抗もしやすい

### 4-3. 制作の流れ

1. モチーフ 90 点＋予備 20 点を難易度順にリスト化
2. お父さんが 1 枚ずつ描く。**この過程を撮影して動画にする**（教材と動画を同時に作る）
3. スキャン → 線画整理 → 淡色化してなぞり枠へ
4. ワークシートの枠にはめる → 検品（比率、濃度、印刷テスト）
5. PDF 化（印刷用・タブレット用）、PNG 書き出し

「1枚描く＝1本の動画になる」ので、教材制作と動画投稿の工数が重なる。ここが個人でも回せる理由になる。

## 6. チャンネルと SNS の使い方

### 6-1. 導線

```
YouTube 本編（お父さんが「今日の1枚」を描く。子どもも描く）
  → 概要欄・固定コメント（無料お試し版）
    → BOOTH（有料パック）
      → 購入者が「1日目と30日目」を投稿 → 動画で紹介 → また売れる
```

### 6-2. 投稿の型

| 媒体 | 型 | 頻度 |
|---|---|---|
| YouTube 本編 | 「模写ドリル Day N」シリーズ。お父さんが描き、子どもが横で描き、最後に並べて比べる | 週2本（教材制作と兼ねる） |
| YouTube ショート | なぞり→自力の 30 秒タイムラプス、子どものビフォーアフター | 週3本 |
| Instagram | 親向け。「絵が苦手な親でもできる声かけ」カルーセル、完成写真 | 週2本 |
| X | 補助。発売告知と購入者作品のリポスト | 随時 |
| note | 「親子で模写する時の声かけ 10 個」など無料記事 | 月1〜2本 |

ハッシュタグは 10 個程度に絞る。#おえかき #親子 #お絵描き #模写 #小学生 #おうち時間 など。

### 6-3. コミュニティ化

- 「#おえかきお父さんドリル」のタグを作り、購入者の投稿を動画・SNSで紹介する
- 30 日目の比較シートをそのまま撮れば投稿になる形にする
- 動画内で「今週のみんなの1枚」コーナーを設ける。子どもは自分の絵が動画に出ると続ける

### 6-4. 発売までのスケジュール案

| 週 | やること |
|---|---|
| 1〜2 | 方針決定、モチーフ 110 点のリスト化、ワークシート枠の設計と印刷テスト |
| 3〜6 | 基礎パック 30 枚を描く＝動画 30 本分を撮る。撮った順に「Day N」として投稿開始 |
| 7 | 無料お試し版を配布。反応で枠・濃度・チェック表を修正 |
| 8 | 基礎パック発売（動画で発売回を作る） |
| 9〜14 | 発展パック制作・発売 |
| 15〜20 | 応用・カラー追加・3段階セット発売 |
| 21〜 | 大人版、季節版、ペーパーバック、メンバーシップ検討 |

## 8. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 「無料プリントで十分」と思われる | 売れない | 無料版は「体験」、有料版は「30日の道筋＋動画＋親子チェック」と価値を分ける |
| 続かない | レビュー低下 | 1日1枚の軽さ、シール欄、動画で「みんなの1枚」紹介 |
| 無断転載 | 売上減 | 透かし、購入者名入り PDF、BOOTH の DL 制限。手描きなので著作権主張は明確 |
| 動画と教材の両方で工数が破綻 | 遅延 | 「1枚描く＝1本撮る」を崩さない。編集は最小限（固定カメラ・カット少なめ） |
| 登録者数が販路条件に届かない | YouTube ショッピング不可 | BOOTH＋概要欄で問題なく売れる。連携は後から足す |
| 印刷環境がない家庭 | 使えない | タブレット用 PNG を同梱。将来はコンビニプリント（ネットプリント）番号配布やペーパーバック |
| 子どもの顔出し | 安全面 | 手元と絵だけの構図を基本にする（既存動画の方針に合わせる） |

---

## 9. 決めてほしいこと

1. **登録者数と再生数の現状**（こちらで取得できなかった）。1,000 人以上かで販路が変わる
2. **メインは親子でよいか**。大人版を先に出す選択もある
3. **画風**: チャンネルの普段の絵柄（アニメ寄り / ゆるかわ / 写実寄り）に合わせる。基礎はどれでも成立するが、発展以降で分岐する
4. **1 枚 1 動画の運用**ができるか。できないなら「5 枚に 1 本のまとめ動画」に落とす
5. **販路**: BOOTH 一本で始めてよいか
6. **お試し版の配布方法**: BOOTH の 0 円商品か、Google ドライブの直リンクか

---

## 10. 決定後の最初の作業

1. ワークシートのテンプレート（A4・枠・親子チェック欄・QR 位置）を 1 枚試作し、家庭用プリンタで印刷して確認する
2. 基礎パックのモチーフ 30 点を難易度順にリスト化する
3. お手本を 3 枚描き、撮影 → 淡色化 → 印刷 → 実際に子どもに描いてもらう
4. 商品ページ用の説明文と「お手本は手描き」の明記文を書く
