## 0. 前提と結論

**前提（解釈）**
「模写」は「イラストのお手本を見て描き写す練習」と解釈した。
書写・文章の書き写しではない。もし後者なら設計を組み直すので指摘してほしい。

**結論（推奨案）**

| 項目 | 推奨 |
|---|---|
| コンセプト | 「30日で"見て描ける"がわかる、段階式の模写ワークブック」 |
| 最大の差別化 | 競合にない「基礎→発展→応用の一本道カリキュラム」と「同じモチーフで白黒→カラーへ連続する設計」 |
| メインターゲット | 絵を描き始めて1年未満の中高生〜30代（SNSで練習投稿をしている層） |
| サブ展開 | 親子版（Fohgの既存導線「親子向け有料ツール」と整合） |
| 販路 | 無料お試しをFohgサイトとXで配布 → 有料本体はBOOTH。Kindleは後発の紙版（ペーパーバック）で参入 |
| 価格帯 | 各レベル980〜1,480円、3段階セット2,980円 |
| 最大リスク | 絵描き界隈のAI生成物への反発。素材の作り方と表示方針を先に決める必要がある（4章） |

## 1. 競合分析

### 1-1. 直接競合（模写・描き込み式の練習教材）

| 商品 | 販路 | 価格 | 分量 | 強み | 弱み（＝こちらの隙） |
|---|---|---|---|---|---|
| hide channel「絵の練習帳」月刊 PDF | BOOTH | 1,800円 | 178ページ/号 | YouTube配信と連動、ポーズ量が圧倒的 | 段階性なし。「素材集」であり「カリキュラム」ではない。初心者は何から手を付けるか迷う |
| 季月エル「トレス＆模写を使った練習術」 | BOOTH | 500円 | 62ページ | 方法論が明確、低価格 | 解説本で練習素材そのものが少ない。2018年発売で古い |
| ホビージャパン「線の描き方ドリル」 | 書店/Kindle | 1,980円 | 128ページ | 薄グレーのなぞり線→本番線の二段構え。直線→曲線→顔→全身の段階設計 | 白黒の「線」だけで終わる。色・陰影に進めない |
| 成美堂「描きこみ式 ゆるっとかわいいイラスト練習帳」 | 書店 | 1,100円 | 159ページ | お手本＋練習スペース、動物・人物の網羅 | 「ゆるかわ」一択で、写実寄り・立体寄りに進む道がない |
| 大泉書店「マンガデッサン練習ドリル 基本編」 | 書店 | 990円 | 96ページ | 30日構成、なぞるだけで練習になる | 2017年刊。カラーなし。基本編で止まる |

### 1-2. 間接競合・代替手段

| 種類 | 例 | こちらへの影響 |
|---|---|---|
| 無料プリント | ちびむすドリル、学習プリント.com「まねして描いてみよう Step1/2」 | 幼児〜低学年向けは無料が強い。親子版は「無料の上位」と位置づける必要がある |
| note・ブログの無料ノウハウ | KUA「確実に画力がUPする模写の練習法」、「画力が上がる模写と上がらない模写の違い」 | やり方の知識は無料で手に入る。売れるのは「知識」ではなく「用意された練習環境」 |
| アプリ | シンプルトレース、MediBang、CLIP STUDIO | デジタル勢にはトレース機能がある。紙で描く層・タブレットで描く層の両方に対応する形式が要る |
| 添削サービス | ココナラ（500円〜、月額伴走型） | 個別添削は真似できない。代わりに「自己採点チェックリスト」で近い価値を出す |
| AI塗り絵（Kindle） | 「大人のAI塗り絵」など多数 | 大量参入で価格競争と低評価が起きている。「塗るだけ」「個性のない線画」は選ばれない。同じ轍を踏まない |
| 海外デジタル教材 | Etsy/Gumroad の drawing practice worksheets（1ドル〜） | 英語圏は薄利多売。日本語で「カリキュラム」を売る方が単価を保てる |

### 1-3. ポジショニングの空白

競合を「価格」と「段階設計の有無」で並べると、次の位置が空いている。

- **段階設計あり × 白黒からカラーまで連続 × 1,000〜1,500円/レベル**

既存品は「素材集（段階なし）」か「線だけのドリル（カラーなし）」のどちらか。
両方を満たし、かつ自己チェックの仕組みまで持つ商品はない。ここを取る。

### 1-4. 競合から学ぶ「守るべき型」

- 薄いグレーの下絵をなぞる→隣の枠に自力で描く、の二段構え（線の描き方ドリル）
- 「30日」という区切り（マンガデッサン練習ドリル）。SNSチャレンジとも相性がよい
- お試し版を別商品として無料配布（hide channel「絵の練習帳お試し版」）
- タブレット用軽量PDFとPC用高画質PDFの2本立て（季月エル）

## 3. 商品設計

### 3-1. 3段階カリキュラム

各レベルは「30枚＝30日分」を基本単位とする。

| レベル | 狙う力 | 課題の中身 | モチーフ |
|---|---|---|---|
| **基礎** | 線を引く力、形を捉える力、比率 | 直線・曲線・楕円 → 幾何図形の組み合わせ → シルエット模写 → グリッド模写 | 果物、器、葉、単純な動物、小物 |
| **発展** | 立体、陰影、構造 | 明暗3段階 → 5段階のグレースケール模写 → 光源を変えた同一モチーフ → 部分模写（手・顔パーツ・布のしわ） | 動物、人物バストアップ、静物の組み合わせ |
| **応用** | 構図、色、自分の絵への転用 | 三分割グリッド模写 → 限定色（3色）模写 → フルカラー模写 → 記憶模写 → 「お手本を変形して描く」課題 | 人物全身、複数モチーフ、簡単な背景 |

### 3-2. 1枚のワークシートの構造（全レベル共通）

1. **お手本**（左上）
2. **なぞり枠**（薄いグレーの下絵。基礎では必ず、発展以降は任意）
3. **自力模写枠**（グリッド付きと無しを選べる）
4. **記憶模写枠**（お手本を隠して描く。発展以降）
5. **チェックリスト**（3〜5項目。例:「全体の縦横比は合っているか」「一番暗い所はどこか」）
6. **今日のポイント**（1〜2行の解説）

見開き・A4縦・余白は印刷を前提に上下左右15mm以上。

### 3-3. 白黒版とカラー版の関係

同じモチーフ番号で白黒とカラーを対応させる。「白黒で形と明暗をつかむ → 同じ絵をカラーで塗る」と連続する。

| 版 | 内容 | 目的 |
|---|---|---|
| 白黒版・線画 | 線のみ | 形と比率 |
| 白黒版・グレースケール | 3〜5段階の明暗 | 立体と光。グリザイユ画法の土台 |
| カラー版・限定色 | 3色まで | 色の役割を減らして「配色」を学ぶ |
| カラー版・フルカラー | 完成イラスト | 色模写。「カラーデッサン」に相当 |

基礎パックは白黒のみ。発展からグレースケール、応用からカラーが入る。
カラー版を独立の「追加パック」としても売れるようにファイル構成を分ける。

### 3-4. バリエーション展開（初回リリース後）

- モチーフ別パック: 動物 / 人物 / 静物・小物 / 背景
- 親子版: モチーフを単純化、なぞり枠を大きく、チェックリストを「親子で確認する言葉」に置換
- 季節版・ネタ切れ対策: ハロウィン、年賀状用など
- 形式別: 印刷用PDF、タブレット用PNG（1枚ずつ、レイヤー分け）、CLIP STUDIO用ファイル

### 3-5. 教育設計（教員としての強みを出す部分）

- **学習ループ**を毎枚に埋め込む: 観察 → 模写 → お手本と重ねて比較 → 修正点を書く → 記憶模写
- **ルーブリック**（3段階の自己評価表）を各レベル冒頭に置く
- **30日カレンダー**と**ビフォーアフター記録シート**を同梱。1日目と30日目に同じモチーフを描かせ、SNS投稿を促す
- 「うまく描けない」の原因診断ページ（比率か、線か、明暗か）

これは競合のどれにもない。「教材として設計されている」ことが最大の売り文句になる。

## 4. 素材の作り方とAI利用の方針（最重要リスク）

### 4-1. リスク

- イラスト・絵描き界隈にはAI生成物への強い反発がある。ターゲットAはまさにその界隈にいる。「AI生成」と分かった瞬間に炎上・不買につながる可能性がある
- AI生成画像は手指や構造が破綻しやすい。**破綻した絵を模写させると初心者に悪影響**が出る。教材としては致命的
- Kindle AI塗り絵は「個性のない線画」で低評価と価格競争に陥っている
- 特定作家の作風・既存キャラの模倣は著作権リスク。生成物そのものには著作権が認められない可能性があり、コピー品への対抗が難しい

### 4-2. 対策（3案）

| 案 | 内容 | 費用/工数 | リスク |
|---|---|---|---|
| ① 全て手描き（自作または外注） | 描き手に1枚数千円で発注。90枚で20〜40万円規模 | 高 | 低。堂々と売れる |
| ② AIで下絵→人が清書・修正（推奨） | AIは構図・モチーフ案とラフ担当。線画は人が引き直し、明暗と色も人が整える | 中 | 中。「AI補助」を明記すれば説明がつく |
| ③ AI生成そのまま | 生成→軽い修正→掲載 | 低 | 高。ターゲットAでは売れない・炎上する |

**推奨は②。** さらに次を守る。

- モチーフは**静物・動物・幾何・風景を主体**にし、人物は発展以降に絞る（破綻と作風問題を避ける）
- 手指・顔は必ず人が描き直す。全枚を「模写して問題ない絵か」の目で検品する
- 使用ツールの規約で商用利用・再配布可を確認し、生成日時・プロンプトを記録して残す
- 商品ページに制作方法を明記する（BOOTHはAI生成作品のタグ付けルールがある）
- 親子版（ターゲットB）はAI反発が弱いので、②の運用でも比較的安全

### 4-3. 判断を仰ぎたい点

「①手描き中心」か「②AI下絵＋手清書」かで、制作費と発売時期が大きく変わる。
自分で線を引き直せるか、外注するかも含めて決めてほしい。

## 6. SNS戦略

### 6-1. 導線

```
X / Instagram（練習投稿・ビフォーアフター）
  → 固定ポスト（無料お試し版の案内、ロードマップ図解）
    → Fohgサイト（無料お試し版DL、メール不要）
      → BOOTH（有料本体）
```

Fohgの「無料で配って、気に入ったら有料へ」という既存の思想と一致する。

### 6-2. 投稿の型

| 媒体 | 型 | 頻度 |
|---|---|---|
| X | 「今日の1枚」お手本＋なぞり動画、ビフォーアフター、上達ロードマップ図解 | 毎日1本 |
| Instagram リール | なぞり→自力模写の15秒タイムラプス | 週3本 |
| Instagram カルーセル | 「比率が合わない時の見方」など1テーマ解説 | 週1本 |
| note | 模写の考え方（無料記事） | 月2本 |

ハッシュタグは10個程度に絞る。核となるもの: #イラスト #絵描きさんと繋がりたい #模写 #絵の練習 #イラスト初心者。
Instagramは30個付けると逆効果という指摘が複数ある。

### 6-3. コミュニティ化

- 「#30日模写チャレンジ」のタグを作り、購入者の投稿をリポストする
- 1日目と30日目の比較投稿をテンプレ化（記録シートをそのまま撮ればよい形にする）
- 購入者の作品がそのまま広告になる。AI塗り絵勢が伸びない原因は「体験の発信がない」点にある

### 6-4. 発売までのスケジュール案

| 週 | やること |
|---|---|
| 1〜2 | 方針決定、モチーフ90点のリスト化、テンプレート（ワークシート枠）設計 |
| 3〜6 | 基礎パック30枚制作＋検品。並行してXで「今日の1枚」投稿開始（認知づくり） |
| 7 | 無料お試し版をFohgとXで配布。反応で修正 |
| 8 | 基礎パック発売 |
| 9〜14 | 発展パック制作・発売 |
| 15〜20 | 応用パック・カラー版・3段階セット発売 |
| 21〜 | 親子版、モチーフ別パック、ペーパーバック検討 |

## 8. リスク一覧と対策

| リスク | 影響 | 対策 |
|---|---|---|
| AI生成への反発 | 不買・炎上 | 4章の②案、明記、モチーフを非人物寄りに |
| お手本の破綻 | 教材の信頼失墜 | 全枚検品、手指・顔は人が描き直す |
| 無断転載・コピー | 売上減 | 透かし、購入者名入りPDF、BOOTHのDL制限。生成物単体に著作権が認められない可能性を前提に、解説文・構成に独自性を持たせる |
| 「無料で十分」と思われる | 売れない | 無料版は「体験」、有料版は「30日の道筋」と価値を分ける |
| 継続率が低い | レビュー低下 | カレンダー、チャレンジタグ、1日1枚の軽さ |
| 販路手数料の改定 | 利益減 | BOOTH＋noteの2本立て、STORES移行余地を残す |

## 9. 決めてほしいこと

1. **「模写」の意味**: イラスト模写で合っているか
2. **素材の作り方**: 手描き中心か、AI下絵＋手清書か。清書を自分でやるか外注か
3. **メインターゲット**: 中高生〜30代の描き始め層でよいか。親子版を先に出す選択もある
4. **画風**: 写実寄り / アニメ・マンガ寄り / ゆるかわ。基礎はどれでも成立するが、発展以降で分岐する
5. **販路**: BOOTH一本で始めてよいか
6. **Fohgサイトとの関係**: 無料お試し版をFohgに置くか、専用LPを別に作るか
