# 読みの観点システム｜系統表対応版

いただいた「系統表のイメージ」（学年 × 単元 × 観点のマトリクスに ◎、
＋「こうすると生徒が使いやすくなるのでは？」の3点）を、そのまま画面と記録に落とし込みました。

差し替えるファイルは3つです。

| ファイル | 役割 |
| --- | --- |
| `コード.gs` | サーバー側（名簿・単元マスタ・記録・系統表の集計） |
| `index_bungaku.html` | 生徒用（文学的文章） |
| `index_setsumei.html` | 生徒用（説明的文章） |

`menu.html` と `teacher.html` は変更していません（そのままで動きます）。

---

## 1. 何が変わったか

### ① 系統表を、生徒の画面に出しました
画面のいちばん下を「これまでの記録」から **「読みの観点　系統表」** に置きかえました。
いただいた表と同じ向き（**たて＝9つの観点／よこ＝単元**、左に第一層〜第三層）です。

- **◎ ＝ 先生のねらい**（単元マスタの「推奨観点」をそのまま表示）
- **1 / 2 / 3** ＝ その生徒がとどいた深さ、**☆** ＝ 選んだだけ（深さ未記録）
- 記録のある単元だけでなく、**単元マスタに登録した全単元が並びます**。
  つまり「これから学ぶ単元」も見えるので、生徒が見通しをもてます。
- いま学習中の単元の列には「いま」と出ます。右端に **「これまでの最高」** の深さ。
- 表の上に **「つかった観点 5/9」「深さ3までいった観点」「記録した単元」**、
  下に **「まだ使っていない観点：〜」** を出しています。

### ② 観点ごとの具体例を明示しました
各カードに **「具体例を見る」** ボタンを付けました。開くと

- **こう書けたらOK**：実際の教材（少年の日の思い出／ベンチ／オツベルと象／ダイコンは大きな根？／モアイは語る 等）に即した記述の例
- **書き出しの型**：「はじめ〜だった○○は、〜をきっかけに、〜と変わった。（本文「……」から）」のような文型

の2つが出ます。**何をどう書けばいいか分からない**生徒の手がかりになります。

### ③ 文字数を指定できるようにしました
☆で観点をえらぶと、そのカードに **記述らん** が出ます。

- 見出しに「**100字くらい**」と目安を表示（単元ごとに変えられます）
- 下のカウンターが **「61 / 100字　あと 19 字くらい」→「ちょうどいい長さ」→「◯字ほど長い。けずってみよう」** と変化
- 目安の 0.8〜1.3 倍に入ると緑色になります

### ④ 観点読みの結果を、総括的に振り返れるようにしました
カードの下に **「この単元のふりかえり（総括）」** を追加しました。

- 今回えらんだ観点と深さがチップで並ぶので、それを見ながら書けます
- 「いちばん役に立った観点は？」「深さ3に近づけたのはどこ？」「つぎにねらいたい観点は？」の3つの問い付き
- こちらも文字数の目安つき（既定 200字）
- 書いた内容は記録シートの「単元のふりかえり」列に保存されます

## 2. 先生がすること（スプレッドシート側）

### 単元マスタ（＝系統表の設計図）
列が増えました。**既存のシートは、スクリプトを貼り替えて開けば自動で列が足されます**（並べ替え・作り直し不要）。

| 列 | 内容 |
| --- | --- |
| 単元ID | 例：B01（重複しない文字列） |
| **学年**（新） | 1年 / 2年 / 3年（「1」だけでもOK）。系統表の横の見出しになります |
| ジャンル | 文学 / 説明文 |
| 単元名 | 生徒のプルダウンと系統表の見出し |
| 教材名 | 任意 |
| 順序 | 学年の中での並び順 |
| 有効 | TRUE の単元が最初に選ばれます |
| 推奨観点 | **これが系統表の◎**。「登場人物、視点・語り、題名」のように読点区切りで2〜3個 |
| **文字数目安**（新） | 観点1つあたりの記述の目安。空なら100字 |
| **振り返り文字数**（新） | 総括の振り返りの目安。空なら200字 |

いただいた系統表をそのまま入れると、たとえばこうなります。

| 単元ID | 学年 | ジャンル | 単元名 | 順序 | 有効 | 推奨観点 |
| --- | --- | --- | --- | --- | --- | --- |
| B01 | 1年 | 文学 | ベンチ | 1 | FALSE | 登場人物、視点・語り、題名 |
| B02 | 1年 | 文学 | オツベルと象 | 2 | FALSE | 設定、表現の工夫、主題 |
| B03 | 1年 | 文学 | 少年の日の思い出 | 3 | TRUE | 構成、批評・評価、自分に生かす |
| S01 | 1年 | 説明文 | ダイコンは大きな根？ | 1 | TRUE | 話題と問い、文章の構成、要点と要旨 |

（単元マスタが無いときは、この5行を見本として自動で作ります。中身は書きかえてください。）

### 記録シート（文学_記録／説明文_記録）
次の列が自動で右端に増えます。**既存の行はそのまま残ります。**

- `学年`
- `登場人物の記述`〜`自分に生かすの記述`（観点ごとの記述、9列）
- `単元のふりかえり`

### 生徒名簿（任意）
`学年` 列があれば読みます。無ければクラス名（例：１年２組）から学年を判断します。

## 3. 差し替え手順

1. GASエディタで `コード.gs` / `index_bungaku.html` / `index_setsumei.html` の中身を貼りかえる
2. スプレッドシートを開き直し、メニュー **「読みの観点 → 記録シートの列を最新にする」** を1回実行（列の追加）
3. **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**
4. 単元マスタの「学年」「推奨観点」を、系統表のとおりに入力

既存の記録・URL・名簿の設定はそのまま使えます。

---

## 4. 教員画面から使える関数（`teacher.html` を拡張するとき）

- `getSyllabus(genre)` … 系統表の設計（層・観点・全単元・◎）だけを返す
- `getClassSyllabus(klass, genre)` … クラスの生徒ごとに「観点ごとの最高の深さ」と「経験した観点数」を返す
- `getStudentHistory(klass, number, genre)` … 従来どおり。`syllabus` / `records` / `summary` が増えているので、生徒画面と同じ系統表を教員側にも出せます

（`units` と `counts` は従来の形のまま返しているので、いまの `teacher.html` はそのまま動きます。）
