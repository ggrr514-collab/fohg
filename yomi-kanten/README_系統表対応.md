# 読みの観点システム｜閲覧版（系統表対応）

いただいた「系統表のイメージ」（学年 × 単元 × 観点に ◎）をそのまま形にしたものです。

- **生徒の画面は「見るだけ」**。ログインも入力も保存もしません。
- **◎＝その単元で全員がおさえる観点**。教員が単元ごとに決めます。
- データは **「単元マスタ」シート1枚だけ**。生徒の記録はとりません。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `コード.gs` | サーバー側（単元マスタの読み書き／教員判定） |
| `index_bungaku.html` | 生徒用・文学的文章（閲覧のみ） |
| `index_setsumei.html` | 生徒用・説明的文章（閲覧のみ） |
| `teacher.html` | 教員用（おさえる観点の設定・系統表の確認） |
| `menu.html` | 入口（今までのものでOK。変更不要） |

---

## 1. 生徒の画面（見るだけ）

1. **単元バー**……学年・単元名・「いま学習中」。ほかの単元も選んで見られます（見通しがもてます）。
2. **先生からのひとこと**……単元マスタの「ひとこと」がそのまま出ます。
3. **◎ この単元で全員がおさえる観点**……2〜3個を大きく表示。押すとその観点のカードにとびます。
4. **観点カード（9つ）**……観点名／問い（Q.）／**具体例**（「こう読めたらOK」＋「言い方の型」）／**深さの3段階**。
   ◎の観点には「◎ 全員がおさえる」のしるしが付き、枠が金色になります。
5. **系統表**……たて＝9観点、よこ＝1年〜3年の全単元。◎の位置と、観点ごとの「おさえる回数」。
   いまの単元の列は色が濃くなります。
6. ☆やチェック、入力らんは**ありません**。押せるのは「単元の切りかえ」と「具体例の開閉」だけです。

## 2. 教員の画面（`?p=teacher`）

- ジャンル（文学／説明文）を切りかえ、単元の一覧から **「観点を決める」** を押すと編集できます。
  - 学年・単元名・教材名・順序
  - **いま学習中**（生徒の画面で最初に開く単元。同じジャンルで1つだけ）
  - **◎ 全員がおさえる観点**……9つからチェック（2〜3個のめやす。4個以上だと「多いかも」と出ます）
  - **生徒へのひとこと**
- **＋ 単元を追加**で新しい単元を登録できます（単元IDは `B01` `S01` … と自動でつきます）。
- 下の**系統表**で、3年間の見通しを確認できます。◎のマスを押すとその単元の設定が開きます。
  どの単元でもおさえていない観点があると、下に赤字で出ます。
- 編集できるのは、**教員名簿にメールアドレスがある人**だけです。

## 3. 単元マスタ（スプレッドシート）

教員画面を使わず、シートを直接編集しても同じです。

| 列 | 内容 |
| --- | --- |
| 単元ID | `B01`／`S01` など。重複しない文字列 |
| 学年 | `1年`（`1` だけでもOK）。系統表の横の見出しになります |
| ジャンル | `文学` / `説明文` |
| 単元名 | 生徒の画面と系統表に出ます |
| 教材名 | 任意 |
| 順序 | 学年の中の並び順 |
| 有効 | `TRUE` が「いま学習中」。生徒の画面で最初に開きます |
| **おさえる観点** | **これが◎**。観点名を読点でくぎって2〜3個（例：`構成、批評・評価、自分に生かす`） |
| ひとこと | 生徒の画面の上に出るメッセージ（任意） |

いただいた系統表をそのまま入れると、たとえば次のようになります。

| 単元ID | 学年 | ジャンル | 単元名 | 順序 | 有効 | おさえる観点 |
| --- | --- | --- | --- | --- | --- | --- |
| B01 | 1年 | 文学 | ベンチ | 1 | FALSE | 登場人物、視点・語り、題名 |
| B02 | 1年 | 文学 | オツベルと象 | 2 | FALSE | 設定、表現の工夫、主題 |
| B03 | 1年 | 文学 | 少年の日の思い出 | 3 | TRUE | 構成、批評・評価、自分に生かす |
| S01 | 1年 | 説明文 | ダイコンは大きな根？ | 1 | TRUE | 話題と問い、文章の構成、要点と要旨 |

※ 前の版の **「推奨観点」** 列がある場合も、そのまま読み込みます（新しい「おさえる観点」列が空のときだけ）。
　 教員画面で一度保存すると「おさえる観点」列に入ります。

## 4. 入れかえの手順

1. GASエディタで `コード.gs` / `index_bungaku.html` / `index_setsumei.html` / `teacher.html` を貼りかえる
2. スプレッドシートを開き直す（「単元マスタ」に不足列が自動で足されます）
3. **デプロイ → デプロイを管理 → 編集 → バージョン「新バージョン」→ デプロイ**
4. `?p=teacher` を開いて、単元ごとに◎をつける

### 公開設定のめやす
- 「次のユーザーとして実行：**自分**」／「アクセスできるユーザー：**組織内の全員**」
- 教員画面は、ログインのメールが**教員名簿**にある人だけ編集できます。
- メールが取得できない公開設定（全員・匿名可）にすると教員画面は使えません。その場合はシートを直接編集してください。

## 5. 前の版からの変更

- 生徒の入力（☆の選択・深さの記録・記述・ふりかえり）と、その保存を**すべて廃止**しました。
  `文学_記録` / `説明文_記録` シートはもう使いません（消さずに残しておいても害はありません）。
- 生徒名簿の照合・氏名の確認画面も不要になったので削除しました。
- 「推奨観点」→「**おさえる観点**」（全員が必ずおさえる、という意味）に言いかえました。
